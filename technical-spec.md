# «Смена» — техническое задание на приложение школьного расписания

Версия: 0.5, проект для обсуждения. Дата: 9 октября 2026 года.

Этот документ описывает функциональность и порядок реализации. Текущее состояние разработки и запуск описаны в [README.md](README.md). Каждый этап заканчивается работающим результатом для визуального просмотра заказчиком; замечания учитываются перед следующим этапом.

## 1. Назначение

Приложение помогает администратору составлять расписание групп на четверть, видеть недостаток часов и избегать пересечений учителей, групп и кабинетов. Учителя и ученики просматривают опубликованное расписание.

Главные требования:

- простое и быстрое заполнение;
- компактный редактор с перетаскиванием занятий;
- отдельное расписание каждой календарной недели;
- учёт четвертей, каникул и неучебных дней;
- разные варианты продолжительности уроков и перемен;
- контроль часов по каждому предмету каждой группы;
- учёт доступности преподавателей и подходящих кабинетов;
- возможность общих мероприятий и объединённых занятий;
- локальное хранение в SQLite с возможностью последующего перехода на PostgreSQL;
- разработка небольшими проверяемыми этапами без избыточной инфраструктуры и большого набора тестов.

## 2. Границы первой версии и предварительные решения

### 2.1. Подтверждённые требования

Администратор авторизуется и редактирует данные. Учитель и ученик могут только просматривать расписание. Администратор заводит группы, численность, предметы, часы на четверть, учителей, кабинеты и каникулы. У группы есть классный руководитель и может быть основной кабинет. Предмет связан с подходящими преподавателями через их специальности; конкретный учитель выбирается в расписании. Разные недели могут отличаться.

При создании предмета группы преподаватель выбирается поиском по фамилии. Допустимость кабинета зависит от предмета, вида занятия и при необходимости от преподавателя. Например, обычная физика возможна в нескольких кабинетах, лабораторная — только в подходящей лаборатории.

Администратор задаёт время начала занятий группы непосредственно в расписании. В каждом дне есть ячейки с настраиваемым временем; длительность урока по умолчанию — 45 минут. Чтобы группа училась во второй смене, достаточно поставить её занятия на дневное время. Отдельная сущность смены и сквозные номера уроков школы не требуются: прежний пример с 8-м уроком не является ограничением.

Перемены настраиваются глобально отдельно для каждой пары соседних уроков: например, между 1-м и 2-м — 10 минут, между 2-м и 3-м — 10 минут, между 3-м и 4-м — 15 минут. Эти значения автоматически используются при заполнении дня. Администратор может изменить отдельную перемену для конкретного дня группы без изменения глобальных настроек и других дней.

Группа может делиться на подгруппы. В ученическом расписании выбранной группы отображаются занятия всех её подгрупп с указанием, кто, где и когда занимается. Для ученика и учителя предусмотрены отдельные общедоступные страницы: поиск группы и поиск преподавателя по фамилии соответственно.

Один урок, включая сокращённый, засчитывается как один учебный час плана. Администратор редактирует черновик и публикует его кнопкой «Опубликовать». Первое хранилище — SQLite; выбор остальных технологий поручен исполнителю.

### 2.2. Предлагаемые решения, которые ещё нужно подтвердить

Эти решения позволяют описать первый вариант и не считаются ответами заказчика на предыдущие вопросы.

| Вопрос | Предложение для первой версии |
| --- | --- |
| Состав подгрупп | Для первой версии одно постоянное разбиение группы на непересекающиеся подгруппы, например 5А/1 и 5А/2; списки учеников не ведутся |
| Масштаб | Одна школа, один администратор; несколько учителей и групп |
| Область публикации | Публиковать согласованное расписание всей школы на выбранную четверть |
| Учебная неделя | Настраиваемые учебные дни; исходный пример — понедельник–пятница |
| Число уроков | По умолчанию семь ячеек на день, можно добавлять и убирать пустые. Номер обозначает позицию внутри дня группы и не определяет время |
| Быстрое заполнение времени | После задания начала первого урока предлагать время следующих по длительности уроков и перемен; все значения можно изменить вручную |
| Фактическое проведение | Первая версия считает запланированные часы, без журнала фактически проведённых занятий |
| Вместимость | Если указана, проверяется по суммарному числу учеников участников |
| Мероприятия | Можно занимать один или несколько уроков либо задавать начало и конец вручную |
| Автораспределение | Отдельная функция-помощник; базовая версия уже работает, дальнейшие улучшения — по выявленным проблемам |

Основные решения о подгруппах, единице часов, открытом просмотре и публикации приняты. Для макета используем одно постоянное разбиение группы. Если состав подгрупп различается по предметам, это нужно уточнить перед реализацией хранения; остальные настройки можно уточнять на соответствующих этапах.

### 2.3. За пределами первой версии

Электронный журнал, оценки, домашние задания, посещаемость, персональные карточки учеников, родительские кабинеты, рассылки, интеграции с внешними системами и сложная оптимизация расписания не входят в первую версию.

## 3. Термины и данные

Слово «класс» в интерфейсе не должно одновременно означать группу и помещение. Используем «Группа» и «Кабинет».

| Сущность | Основные данные и смысл |
| --- | --- |
| Учебный год | Название, даты начала и окончания |
| Четверть | Название, начало и конец, принадлежность учебному году |
| Группа | Название, численность, классный руководитель, основной кабинет, предпочтительные кабинеты для автосоставления |
| Подгруппа | Родительская группа, название и численность; участник занятий со своим преподавателем и кабинетом |
| Преподаватель | Фамилия, имя, отчество; преподаваемые предметы; необязательный кабинет по умолчанию; доступность по времени на будущем этапе |
| Предмет | Название, короткое название, цвет; требуемые типы кабинетов для обычных и лабораторных занятий |
| План группы на четверть | Группа, четверть, предмет, вид занятия, режим «Вся группа / По подгруппам», необходимое число часов по участникам; преподаватель и кабинет здесь не задаются |
| Кабинет | Название/номер, тип или возможности, необязательная вместимость |
| Вид занятия | Обычное занятие или лабораторное; требования к кабинету |
| Ячейка дня группы | Группа, дата, позиция, начало и окончание; может быть пустой или содержать занятие |
| Индивидуальная перемена дня | Группа, дата, пара соседних позиций и длительность, отличающаяся от общих настроек; локальное переопределение |
| Занятие | Дата, фактическое начало и окончание, предмет, вид, преподаватель, кабинет; участники — целые группы или подгруппы, с привязкой к ячейкам их расписаний |
| Мероприятие | Название, дата, время, участники, место, ответственные преподаватели при необходимости |
| Профиль времени и перемен | Название, начало дня, длительность уроков (исходно 45 минут), число ячеек и перемены после них; шаблон для заполнения времени |
| Исключение календаря | Диапазон дат, название, причина, вся школа или выбранные группы |
| Черновик и публикация | Редактируемое состояние расписания и доступная читателям опубликованная версия |

Классный руководитель не обязан вести все предметы группы. Основной кабинет — предпочтение при подборе, а не безусловный запрет других помещений.

У преподавателя кабинет по умолчанию служит подсказкой, а не ограничением. Необходимый тип помещения задаётся предмету и виду занятия; фактический кабинет — конкретному уроку.

Справочники, на которые уже ссылаются занятия, нельзя незаметно удалять вместе с расписанием. Использованные записи можно отправить в архив; существующие занятия сохраняются.

### 3.1. Подгруппы

Администратор создаёт подгруппы внутри группы и указывает их численность. Предлагаемое ограничение первой версии — одно постоянное разбиение: подгруппы не пересекаются и вместе охватывают всю группу. Например, 5А из 28 учеников делится на 5А/1 и 5А/2 по 14. При завершении настройки сумма численности должна совпадать с численностью группы.

Предмет может преподаваться всей группе или по подгруппам. Во втором случае учитель и кабинет выбираются в расписании для каждого занятия подгруппы. Норма часов группы по умолчанию применяется к каждой подгруппе; при необходимости администратор может задать разные нормы явно. Разные подгруппы могут заниматься одновременно или в разное время.

Если нужны разные составы подгрупп по разным предметам, одного названия и количества учеников недостаточно, чтобы определить пересечения участников. Такое расширение требует отдельного описания составов или их пересечений до реализации; первая версия не предполагает, что произвольные подгруппы автоматически независимы.

Настройки календаря, времени и перемен подгруппы наследуют от родительской группы. Параллельные занятия отображаются внутри её ячейки отдельными карточками. Если подгруппе нужно другое время, оно задаётся для её занятия отдельно и показывается на карточке; общие настройки группы сохраняются. Сдвиг дня группы учитывает занятия всех её подгрупп и показывает все изменяемые интервалы до применения.

## 4. Основные сценарии

### 4.1. Первичное заполнение

1. Администратор входит в приложение.
2. Указывает учебный год, четверти и учебные дни недели.
3. Задаёт обычное начало дня, длительность урока (по умолчанию 45 минут) и перемены для всей школы; сокращённые дни задаёт позднее прямо в расписании.
4. Вносит каникулы и отдельные неучебные дни.
5. Добавляет кабинеты, предметы и преподавателей.
6. Создаёт группы, указывает численность, классного руководителя и основной кабинет; при необходимости задаёт группе своё обычное начало дня.
7. При необходимости создаёт подгруппы. Для каждого предмета выбирает обучение всей группой или по подгруппам, заполняет часы на четверть; преподавателя выбирает в расписании.
8. Переходит к составлению расписания.

Справочники можно дополнять прямо во время работы: например, кнопка «Добавить преподавателя» рядом с поиском. После сохранения пользователь возвращается к прежнему месту и введённые данные не теряются.

### 4.2. Ежедневная работа

Администратор выбирает группу и четверть, расставляет занятия, копирует подходящие недели, вносит исключения, проверяет часы и публикует изменения. Учителя и ученики видят опубликованную версию.

## 5. Экран составления расписания

### 5.1. Общая компоновка

Основной рабочий экран рассчитан на компьютер. На телефоне в первую очередь должен быть удобен просмотр.

```text
Группа [5А ▾]  Четверть [I ▾]  [Сегодня] [←] [→]   Сохранено · Черновик
[Проверить] [Копировать неделю] [Отменить]                 [Опубликовать]

Предметы       Карточки занятий          Неделя с 05.10.2026
Поиск…         Физика                    №          Пн  Вт  Ср  Чт  Пт
Матем. 20/40   ┌────────────────────┐    1          …   …   …   …   …
Русский 18/32  │ Физика · Иванов И.И.│    2          …   …   …   …   …
Физика  6/18   │ Обычное занятие    │    3          …   …   …   …   …
              └────────────────────┘    …
              [Лабораторная]             7          …   …   …   …   …

                                        Неделя с 12.10.2026 [развернуть]
```

Порядок областей сохраняет предложенную заказчиком схему: предмет → предмет с преподавателем → календарь.

Каждый день содержит несколько ячеек; по умолчанию семь, но их количество можно менять. Внутри ячейки компактно показан редактируемый интервал, например «14:00–14:45». Номер строки обозначает только позицию в дне группы. Дни могут начинаться в разное время, поэтому общей шкалы времени слева нет. Утренние пустые строки для группы с дневными занятиями не создаются.

Ориентир ширины первой колонки — 140–170 px, второй — 180–220 px, остальное пространство занимает расписание. Это ориентиры для макета, а не жёсткие размеры. Колонки можно свернуть, чтобы увеличить календарь.

Недели располагаются вертикально. По умолчанию открыта выбранная неделя; можно открыть соседние. Не нужно сразу выводить всю четверть огромной сеткой. Над неделей показывается дата понедельника, у каждого дня — день недели и дата.

При вертикальной прокрутке сохраняются доступными выбор группы, карточки и заголовки текущей сетки. На узком экране календарь допускает горизонтальную прокрутку без сжатия надписей до нечитаемого размера.

### 5.2. Предметы и карточки

В первой колонке находятся предметы выбранной группы. Рядом — число запланированных часов и план на четверть: «6 / 18», с пояснением «Осталось 12» при выборе.

Во второй колонке после выбора предмета показаны карточки всех действующих преподавателей с этой специальностью, в алфавитном порядке. Администратор выбирает карточку или перетаскивает её. Если подходящих учителей нет, предлагается настроить специальности в справочнике. Часы плана общие для всех вариантов преподавателя.

Для предмета с делением во второй колонке показываются отдельные карточки: «Информатика · 5А/1 · Иванов» и «Информатика · 5А/2 · Петров». Внутри ячейки предусмотрены области подгрупп, чтобы было понятно, для кого место уже занято. Параллельное занятие другой непересекающейся подгруппы можно добавить в ту же ячейку при свободных преподавателе и кабинете. Общее занятие занимает ячейку для всей группы.

У физики и химии можно переключить вид занятия «Обычное / Лабораторное». Нормы и счётчики обычных и лабораторных занятий задаются отдельно.

Внизу списка есть отдельная карточка «Мероприятие» для линейки, классного часа и других событий. Классный час может быть предметом с часами либо мероприятием — это явно выбирается при настройке, а не определяется автоматически по названию.

### 5.3. Перетаскивание

1. Администратор выбирает предмет.
2. Перетаскивает карточку с преподавателем в ячейку нужного дня с видимым временем. Время берётся из ячейки; его можно изменить до или после добавления предмета.
3. Свободные допустимые ячейки подсвечиваются; недоступные получают понятное пояснение.
4. Приложение подбирает свободный подходящий кабинет.
5. Если кабинет найден, занятие сразу сохраняется в черновик.
6. Если обязательные условия не выполнены, перенос не завершается, исходное состояние сохраняется, показывается причина.

Примеры сообщений: «Иванов И.И. занят у 7Б, 10:00–10:40», «Оба кабинета информатики заняты», «Для лабораторной нужен кабинет с оборудованием по физике».

Кабинет выбирается сначала из подходящих предпочтительных, затем из остальных разрешённых. Если найдено несколько равнозначных, используется стабильный порядок, чтобы повторные действия давали предсказуемый результат. После размещения кабинет можно заменить вручную.

Перенос уже размещённого занятия на пустую ячейку перемещает его. Перетаскивание карточки из левой панели создаёт новое занятие. Перетаскивание обычного одиночного урока всей группы на другой такой урок обменивает их местами без подтверждения, если оба назначения допустимы. Во время перетаскивания зелёная сплошная рамка означает допустимый перенос или обмен, толстая красная — запрет; причина показывается при наведении. Подгруппы сохраняют обычное размещение в свободной для них ячейке; обмен подгрупп, общих уроков и мероприятий пока не поддерживается.

Альтернативный способ: выбрать карточку, затем нажать на ячейку. Все действия доступны без обязательного перетаскивания.

### 5.4. Ячейка и редактирование

Над ячейкой показывается время. Карточка занятия содержит две строки: сверху сокращённое название предмета и фамилия в скобках, например «Русс. яз. (Иванова)», снизу — кабинет. У подгруппы рядом с кабинетом есть её метка. Полные название и фамилия доступны при наведении и открытии карточки; длинный текст не должен перекрывать соседние элементы. Цвет помогает различать предметы, но не заменяет текст.

Нажатие открывает небольшую боковую панель: дата, позиция в дне, начало, длительность и вычисляемое окончание, предмет, преподаватель, вид занятия, кабинет, примечание. По умолчанию длительность — 45 минут; для сокращённого дня берётся установленная в расписании длительность. Начало и длительность можно менять вручную. Замена преподавателя относится только к выбранному уроку и не меняет норму часов.

При переносе занятия в другую ячейку оно получает её время и длительность. Предварительная подсказка показывает новый интервал; ограничения проверяются до сохранения. Это относится и к переносу между днями с разным началом занятий.

Есть команды «Удалить занятие» и «Отменить последнее действие». Отмена действует для последних изменений текущей сессии редактирования; публикация не отменяется обычной кнопкой отмены.

### 5.5. Ускорение заполнения

- Копировать неделю в одну или несколько выбранных недель.
- Повторить выбранное занятие на те же день недели и позицию в дне в выбранных неделях четверти.
- Быстро перейти к следующей группе, сохранив выбранную неделю.
- Фильтровать предметы, по которым остались нераспределённые часы.

При копировании выбирается режим времени: «По времени целевых дней» (по умолчанию) или «Вместе со временем исходной недели». Первый режим сопоставляет позиции внутри дней и сохраняет целевые интервалы, включая сокращённый день. Второй переносит в свободные позиции также исходные интервалы; изменения времени явно показаны в предварительном результате. Если в целевом дне нет нужной ячейки, она не создаётся скрыто: занятие попадает в список пропусков, администратор может добавить ячейку и повторить действие. Все ограничения проверяются заново. Повтор отдельного занятия по умолчанию использует время целевой ячейки.

Перед массовым действием показывается краткий результат проверки: сколько занятий будет добавлено, сколько пропущено из-за каникул, занятых ячеек или конфликтов. По умолчанию существующие занятия сохраняются, заполняются только свободные места для выбранных участников. У подгрупп свободное место проверяется отдельно; общий урок копируется как одно событие, даже если виден в нескольких расписаниях. Применяются только явно показанные допустимые добавления; результат можно отменить одним действием.

## 6. Учебный календарь, каникулы и звонки

### 6.1. Календарь

Администратор задаёт четверти, общие учебные дни недели, отдельные учебные дни недели для групп, каникулы и отдельные неучебные дни. Например, младшая школа может учиться пять дней, а средняя и старшая — шесть. Группа без отдельной настройки наследует школьные дни; периоды по датам имеют приоритет над обычной учебной неделей. В диалоге периодов даты выбираются в русском календаре с понедельника либо вводятся в формате ДД.ММ.ГГГГ. Диапазоны вводятся включительно: обе граничные даты входят в период.

Начало периода не может быть позже окончания. Четверти одного учебного года не пересекаются и находятся внутри его границ. Каникулы могут находиться между четвертями или перекрывать часть четверти: в обоих случаях дни исключаются из размещения занятий.

Каникулы по умолчанию относятся ко всей школе; можно выбрать отдельные группы. В календаре и расписании такие дни подписаны и визуально отличаются от обычных пустых ячеек.

Обычные уроки в неучебный день не размещаются. Копирование и автораспределение пропускают его. Праздники не загружаются автоматически из внешнего календаря: администратор задаёт их сам.

Отдельная дата может быть явно назначена учебной, например суббота для переноса занятий. Если она попадает в каникулы, интерфейс предупреждает и требует явного выбора «Сделать учебным днём»; результат не зависит от порядка ввода настроек. Индивидуальные исключения групп отображаются рядом с общешкольными.

Если на новые каникулы уже приходятся занятия, перед сохранением показываются затронутые даты, группы и количество занятий. Администратор может отменить изменение либо подтвердить снятие этих занятий в черновике. Опубликованное расписание изменится только после публикации. Счётчики часов черновика пересчитываются сразу.

### 6.2. Время ячеек и общие настройки звонков

Основой расписания являются реальные интервалы времени конкретного дня группы. Администратор может добавить урок, изменить начало, например на 14:00, и получить окончание 14:45 при стандартной длительности. Следующая ячейка предлагается с 14:55, если после предыдущей настроена перемена 10 минут. Число 10 здесь только пример: длительность перемен задаёт администратор.

Для всей школы задаётся одна общая настройка: начало первого урока, длительность уроков и последовательность перемен. Отдельных настроек звонков групп и именованных обычных/сокращённых профилей нет. Сокращённые уроки на одну дату настраиваются прямо в расписании через надпись «Начало в …».

В глобальных настройках перемены представлены простой таблицей: «После 1-го урока — 10 минут», «После 2-го — 10 минут», «После 3-го — 15 минут» и далее. Номер относится к позиции в дне группы: одна последовательность подходит и для утреннего, и для дневного начала. При заполнении следующей ячейки её начало вычисляется как окончание предыдущей плюс соответствующая перемена.

В редакторе дня между ячейками показывается компактная надпись, например «Перемена 15 мин». Нажатие позволяет изменить длительность только для этой группы на эту дату. Изменённое значение помечается «Для этого дня»; рядом доступно «Вернуть по настройкам». Остальные перемены дня сохраняют свои значения. Сохранение локальной правки не изменяет общие настройки, соседние даты или расписание других групп.

Изменение перемены сдвигает следующую и все последующие ячейки на разницу длительностей, сохраняя длительность уроков и остальных перемен. Например, увеличение перемены после 3-го урока с 15 до 20 минут сдвигает 4-й и последующие уроки на пять минут. Для заполненного дня сначала показывается результат и проверяются конфликты; при конфликте не сохраняются ни новая перемена, ни сдвиг. Возврат к настройкам действует так же. Если следующая ячейка ещё не создана, выбранная перемена применяется при её добавлении.

Фактические интервалы конкретного дня имеют приоритет над общими настройками. В диалоге «Начало учебного дня» длительность применяется ко всем ячейкам на эту дату, включая пустые. Поле начала использует 24-часовой формат ЧЧ:ММ. Рядом с длительностью урока находится «Длительность всех перемен, мин» с чекбоксом: с галочкой все перемены дня получают это значение, без галочки восстанавливается последовательность общих школьных перемен. В «Применить на эту дату» доступны текущая группа (по умолчанию), выбранные группы с галочками и все действующие группы. Значение начала применяется только к текущей группе, если она выбрана; у остальных сохраняется фактическое начало дня. При исключении текущей группы поле начала отключается. Предпросмотр показывает каждую выбранную группу, её интервалы до/после и явно пропускает неучебные дни, дни без ячеек и отсутствующее расписание. Новые или усиленные пересечения учителей/кабинетов и расходящиеся интервалы общего занятия блокируют всю операцию, отображая причину; никаких частичных изменений не сохраняется. Изменение времени всех участников общего занятия разрешено, если их новые интервалы совпадают. Применение и отмена охватывают все выбранные группы одним действием. Если возврат исходного расписания восстановит старое пересечение учителя или кабинета, предпросмотр заранее предупреждает, что такая отмена будет запрещена существующей проверкой. Другие даты и невыбранные группы не изменяются.

При создании дня общие настройки заполняют ячейки конкретными интервалами. Ручное время ячейки сохраняется как введено. Изменение общих настроек задаёт новые значения по умолчанию для ещё не созданных дней; существующие ячейки, включая пустые, не пересчитываются молча. Для них есть команда «Применить настройки к расписанию» с предварительным просмотром.

Применение к существующим дням сохраняет начало каждого дня, если администратор отдельно не выбрал его замену; остальные интервалы пересчитываются по общей длительности и переменам с сохранением индивидуальных перемен дня. Их сброс к общим настройкам требует отдельного явного выбора. Ручные отклонения времени, которые будут заменены, выделяются до подтверждения. Сокращение числа ячеек не удаляет занятия: при наличии занятий в убираемых ячейках операция блокируется до их явного переноса или снятия.

Рядом с ячейкой или в панели показывается фактическая перемена до следующего урока. Пересечения ячеек одного дня и отрицательные промежутки не допускаются. Длительность должна быть положительной, начало и окончание относятся к одной дате. Время показывается в часовом поясе школы.

Если начало отдельного урока изменено вручную, изменившиеся промежутки до и после него также становятся индивидуальными переменами этого дня. Отображаемые перемены всегда соответствуют фактическим интервалам. При копировании вместе со временем исходной недели копируются и её индивидуальные перемены; при копировании по времени целевых дней сохраняются перемены целевых дней.

### 6.3. Изменение времени и начала дня

При изменении начала уже заполненного урока доступны два понятных варианта:

- «Только этот урок» — сохраняет его длительность, изменяет его начало и окончание; остальные ячейки остаются на месте.
- «Этот и все последующие» — сдвигает их на одинаковую разницу во времени, сохраняя длительности и промежутки, включая пустые ячейки. Например, перенос первого начала с 08:00 на 14:00 сдвигает день на шесть часов.

Предлагаемый выбор по умолчанию — только этот урок. Нажатие «Начало в …» открывает отдельный диалог всего дня с общей длительностью уроков и необязательной одинаковой длительностью перемен. Он пересчитывает весь выбранный день с предварительным просмотром. Изменение длительности через редактор отдельного урока сохраняет остальные начала.

После любого изменения времени проверяются группа, преподаватели, кабинеты и общие события. Если возникает конфликт, операция целиком не применяется; показываются причина и затронутые занятия. Пустые ячейки задают доступное время для заполнения, но не занимают учителя или кабинет. Удаление предмета освобождает ячейку, сохраняя её время.

Новую пустую ячейку можно добавить после последней: начало предлагается по предыдущему окончанию и настроенной перемене, длительность — из общих настроек или сокращённого дня, исходно 45 минут. Одинаковая локальная перемена сокращённого дня применяется и к добавляемой ячейке. Копирование и автораспределение используют подготовленные ячейки с их реальным временем; автораспределение само не меняет начало дня и не добавляет ночные или иные не заданные администратором интервалы.

## 7. Правила размещения и общие занятия

### 7.1. Обязательные ограничения

Обычное занятие разрешено, если одновременно выполнены условия:

- свободны все участники: целая группа либо выбранные подгруппы;
- преподаватель свободен и доступен в это время;
- преподаватель может вести выбранный предмет;
- кабинет свободен;
- кабинет подходит по предмету, виду занятия и строгим ограничениям преподавателя;
- вместимость достаточна, если она задана;
- день учебный, дата относится к выбранной четверти, у целевой ячейки задан допустимый интервал времени;
- заполнены обязательные данные занятия.

Все пересечения проверяются по реальному времени. Позиция урока в дне не определяет занятость: первые занятия двух групп могут быть утром и днём, а третье занятие одной группы может пересекаться с первым другой. Один учитель или кабинет могут использоваться в обеих группах только без пересечения интервалов. Занятие, заканчивающееся ровно к началу другого, не пересекается с ним.

Проверка учитывает все группы школы, включая те, которые сейчас не открыты в редакторе. Две группы могут одновременно заниматься информатикой в двух разных кабинетах, если у них разные свободные преподаватели. Третью нельзя поставить при отсутствии третьего подходящего кабинета.

Занятие всей группы конфликтует с любым пересекающимся по времени занятием её подгрупп. Два занятия одной подгруппы конфликтуют. Две разные подгруппы одного разбиения могут заниматься одновременно, но учитель и кабинет всё равно должны быть свободны. В кабинете проверяется численность именно участников занятия. Обычный урок двух подгрупп не становится одним общим уроком лишь потому, что у них одинаковые предмет и время.

Недоступность преподавателя задаётся простыми повторяющимися интервалами по дням недели и исключениями на конкретную дату. Сложное нормирование нагрузки остаётся за рамками текущего цикла. Сводная нагрузка, автоматический подбор замен, передача преподавания на период и предпочтения по окнам и сменам добавлены в план расширения перед пробной эксплуатацией (раздел 12).

### 7.2. Предупреждения

Недобор часов, превышение плана и окна в расписании группы подсвечиваются, но сами по себе не блокируют сохранение черновика. Недобор не блокирует публикацию, поскольку четверть может заполняться постепенно; перед публикацией он явно показывается.

Автоматическое соблюдение санитарных норм, максимума подряд и распределения сложных предметов не заявляется. При необходимости конкретные правила добавляются отдельно после согласования.

### 7.3. Объединённый урок

Общий урок нескольких групп или подгрупп хранится как одно занятие со списком участников, одним преподавателем и одним кабинетом. Он отображается у каждой участвующей группы, занимает кабинет один раз и проверяет суммарную вместимость. Одновременно выбрать целую группу и её подгруппу нельзя: участники не должны учитываться дважды.

У общего урока единое начало и окончание для всех участников, хотя позиции в их днях могут отличаться. При создании можно автоматически согласовать время существующих уроков или свободных ячеек с разными интервалами: меняются только выбранные ячейки и соседние перемены, без переноса других занятий. Подходящие группы выбираются из выпадающего списка; предпросмотр показывает интервалы и перемены до/после. Длительность берётся из формы и автоматически не сокращается. При отключении автосогласования используется введённое начало. Изменение времени общего урока обновляет связанные ячейки всех участников после проверки. Обычный массовый сдвиг дня одной группы, затрагивающий общий урок, блокируется с предложением сначала изменить общее занятие: нельзя незаметно сдвинуть расписание других групп.

Один такой урок добавляет по одному часу каждому охваченному плану участников по правилам раздела 8. Участники должны иметь этот предмет в плане. Преподаватель выбирается при создании общего занятия из подходящих по специальности.

Редактирование общего урока из расписания любой группы меняет само общее занятие. Перед изменением показываются затронутые группы. Удаление из одной группы сохраняет урок у остальных, а у единственного оставшегося участника снимает связь объединения. Отмена восстанавливает всё занятие одним действием.

### 7.4. Мероприятие

Для мероприятия задаются название, дата, интервал времени, место и группы: выбранные либо все активные группы школы на момент создания. Этот список сохраняется; добавление новой группы позднее не меняет старые события автоматически.

Актовый зал, спортзал и другие общие пространства учитываются как помещения. Событие занимает помещение один раз и блокирует время всех выбранных групп, включая все их подгруппы. Численность группы считается один раз. Указанные ответственные преподаватели также считаются занятыми. Классные руководители не добавляются в ответственные автоматически без видимого выбора.

Мероприятие не добавляет часы предмета. Если оно заменяет уроки, показывается список затронутых занятий. После подтверждения они снимаются в черновике, часы уменьшаются, событие появляется у всех участников. Занятые посторонним событием помещение или ответственный преподаватель остаются блокирующим конфликтом.

В диалоге доступно два взаимоисключающих флажка, оба по умолчанию выключены для нового мероприятия. «С заменой уроков» удаляет пересекающиеся предметные занятия только выбранных групп; другое мероприятие так не заменяется. «С сохранением остатка урока» делит занятую ячейку на мероприятие и исходный урок, если мероприятие начинается вместе с уроком и короче него. Исходные записи, включая параллельные подгруппы, сохраняются с прежними преподавателями и кабинетами; их начало переносится на конец мероприятия, окончание остаётся прежним, перемена между частями равна нулю. Например, из 45 минут получаются 20 минут мероприятия и 25 минут урока. Когда мероприятие занимает урок целиком или длится дольше, пересекающиеся уроки заменяются полностью. Следующие занятия не сдвигаются. Объединённый урок допускает такое изменение только при выборе всех его участников. Не допускается превышение 12 ячеек в день. Предварительный просмотр перечисляет удаляемые, сокращаемые либо восстанавливаемые уроки; запись требует отдельного подтверждения.

Короткое мероприятие сохраняет связь с исходными уроками и их точным временем для каждой группы; информация переживает сохранение и повторную загрузку базы. При удалении мероприятия или исключении группы из его участников исходное время её урока восстанавливается, а две последовательные ячейки снова становятся одной. Если короткое мероприятие занимало пустую ячейку, восстанавливается длительность этой пустой ячейки. Восстановление не меняет последующие занятия и не возвращает полностью заменённые уроки. Оно допускается только при точном совпадении сохранённого разделения: дата, начало, длительности, идентификаторы и состав оставшихся уроков. Ручные изменения не перезаписываются; несовпадение или новый конфликт преподавателя, кабинета либо недоступности блокирует всю операцию. Старые мероприятия без сохранённой связи с уроком не восстанавливаются по предположениям.

В палитре остаётся одна карточка «Мероприятие»; линейка вводится как его название. В расписании мероприятия отмечены золотистым цветом и значком календаря, который сохраняется при отключении значков предметов. Ответственный выбирается через выпадающий список с поиском по части ФИО. Группы выбираются стандартным компонентом с поиском `!1` / `!1а`; над выбором перечислены выбранные группы через запятую. Неподходящие кабинеты скрыты из списка, причины доступны через соседнюю подсказку `i`.

## 8. Контроль часов

Для каждого предмета группы в четверти выводятся:

- план;
- запланировано;
- осталось распределить или превышение.

Например: «Физика: 18 по плану · 16 запланировано · не хватает 2».

Для предмета по подгруппам счётчики ведутся отдельно: «5А/1: 8/18; 5А/2: 7/18». Два параллельных урока разных подгрупп дают по одному часу каждой, а не два часа всей группе. Нельзя складывать их в единый счётчик выполнения плана группы. В свёрнутом виде показывается наличие недобора, по раскрытию — все подгруппы.

Если предмет обычно идёт по подгруппам, одно общее занятие всей группы по этому предмету даёт по одному часу каждой подгруппе, поскольку участвуют все. Повторно этот же урок в план целой группы не добавляется. Для предмета с режимом «Вся группа» используются общие занятия; переход к учёту по подгруппам — явное изменение плана с пересчётом и предварительным результатом.

Учитываются конкретные занятия на даты четверти. Копии недель считаются по созданным занятиям; снятые занятия и мероприятия без предмета не учитываются. Прошедшая дата сама по себе не превращает запланированный урок в фактически проведённый.

Администратор видит счётчик текущего черновика, при необходимости — сравнение с опубликованным расписанием. Ученикам и учителям служебные счётчики не нужны.

Есть общая таблица «Часы»: группы по строкам, предметы и дефицит в раскрываемых деталях. Фильтр «Есть недобор» позволяет найти проблемные группы без открытия каждой недели.

Если оставшихся свободных позиций в подготовленном расписании меньше нужного числа уроков, показывается дополнительное предупреждение: «Осталось 10 свободных мест, нужно распределить 14 уроков». Для группы с делением проверка выполняется отдельно для каждой подгруппы: общие уроки занимают время всех, занятия другой подгруппы сами по себе не отнимают её позицию. Общие недостающие уроки включаются в потребность каждой подгруппы один раз. Обратное не доказывает выполнимость: могут мешать ограничения учителей и кабинетов. Первая версия не обещает математически доказать возможность заполнить весь план.

## 9. Черновик, сохранение и публикация

Изменения автоматически сохраняются в черновик. Видно состояние: «Сохраняется», «Сохранено», «Не удалось сохранить». При ошибке нельзя показывать успешное сохранение или терять несохранённые изменения без предупреждения.

Для простоты предлагается один общий черновик школы на четверть. Команда «Опубликовать» публикует согласованное состояние всей четверти и всех групп, а не только открытую группу. Это исключает частичную публикацию общего события и уменьшает риск конфликтов между группами.

Перед публикацией показываются число изменённых занятий, затронутые группы, ошибки и предупреждения. Обязательные конфликты блокируют публикацию; недобор часов отображается как предупреждение. Пользователи продолжают видеть предыдущую опубликованную версию до успешного завершения.

Расписание и влияющие на него время/подписи должны публиковаться согласованно. Изменение общих настроек звонков или фамилии в черновике не должно незаметно менять уже опубликованное занятие. Для первой версии допустим простой снимок опубликованных данных без сложной системы версий.

Повторное нажатие или повтор запроса после сетевой ошибки не должны создавать дубликаты занятий. Сохранение общего события, массовое копирование и публикация выполняются целиком, без половины применённых изменений.

История всех редакций и совместное редактирование несколькими администраторами в первую версию не входят. Если обнаружено изменение из другой вкладки, нужно предложить обновить данные, а не молча перезаписать их.

## 10. Просмотр учителем и учеником

Две отдельные общедоступные страницы: «Ученикам» (`/students`) и «Учителям» (`/teachers`). Между ними доступны ссылки; вход для просмотра не требуется. Администратор входит отдельно через `/admin`.

На странице ученика — поиск группы по названию и выбор из результатов, например «5А». На странице учителя — поиск по фамилии с выбором конкретного преподавателя; для однофамильцев показываются имя и отчество. Поиск не является авторизацией. Последний выбор сохраняется в браузере отдельно для каждой страницы.

По умолчанию открывается текущая учебная неделя с выделением сегодняшнего дня. Если она закончилась или сейчас каникулы, предлагается ближайшая следующая неделя с опубликованными занятиями. Когда будущего расписания нет, показывается понятное сообщение и возможность перейти к прошедшим неделям.

Навигация: предыдущая/следующая неделя, «Сегодня», выбор даты и четверти. Для четверти показывается список недель с датами и возможностью открыть нужную; не требуется умещать всю четверть в одну сетку.

На компьютере — компактная сетка недели. На телефоне — дни вертикальными карточками, внутри которых занятия идут по времени.

У ученика на первом плане предмет, время, преподаватель и кабинет. У учителя — предмет, группа и кабинет. В каждой карточке виден фактический интервал; например, первое занятие группы может быть в 14:00. Позиция внутри дня — вспомогательная подпись. Общее занятие показывает всех участников. Каникулы, неучебный день и отсутствие опубликованных данных имеют разные подписи.

Ученик всегда видит все подгруппы выбранной группы. Например, в одном интервале: «5А/1 — Информатика · Иванов · каб. 201» и «5А/2 — Информатика · Петров · каб. 202». У каждой карточки своё время, если оно различается. На телефоне карточки подгрупп идут одна под другой с явными названиями. Занятие всей группы показывается один раз с подписью «Вся группа», а не повторяется для каждой подгруппы.

На странице преподавателя отображаются только его занятия, с названием группы или подгруппы и кабинетом. Один объединённый урок показывается одной карточкой со всеми участниками, без дублирования.

Для учителя занятия из групп с разными звонками сортируются по фактическому времени. Номер урока можно показывать дополнительно, но он не заменяет время.

Доступен только просмотр. В интерфейсе нет кнопок редактирования; сервер также запрещает изменения без входа администратора. Отображается дата последней публикации. Автоматические уведомления не требуются.

## 11. Простая техническая организация

Выбран обычный браузерный интерфейс и одно серверное приложение с одной базой данных:

- TypeScript — общий язык интерфейса и сервера.
- React и Vite — интерфейс, локальная разработка и сборка.
- Node.js 24 LTS и Fastify — небольшой сервер с API и авторизацией администратора.
- PostgreSQL 18 через pg — основное хранилище; простой слой асинхронных запросов без ORM и последовательные SQL-миграции. SQLite через better-sqlite3 сохраняется для явного переноса прежних данных и существующего тестового контура.
- Обычный CSS и небольшие компоненты; дополнительные библиотеки добавляются только под конкретную потребность.

После сборки сервер раздаёт и интерфейс, и API с одного адреса. Отдельный процесс Vite нужен только при разработке. Версии зависимостей фиксируются при создании проекта, а установка и сборка проверяются на целевом компьютере. Выбор драйвера SQLite не отменяет отдельную работу по переносу запросов и данных при переходе на PostgreSQL.

Совместимость стека проверена по официальным источникам: [требования Vite](https://vite.dev/guide/), [поддержка Node.js в Fastify](https://fastify.dev/docs/latest/Reference/LTS/), [ветки Node.js](https://nodejs.org/en/about/previous-releases), [установка better-sqlite3](https://github.com/WiseLibs/better-sqlite3#installation). На первом этапе используются демонстрационные данные; сервер и база подключаются на втором.

PostgreSQL хранит общие данные школы на сервере базы данных. Это не хранилище отдельного браузера. Учитель и ученик смогут обращаться с других устройств, если сервер доступен им по сети; пока он выключен, общего доступа нет. Публикация расписания внутри приложения не означает автоматическое размещение приложения в интернете.

Для PostgreSQL:

- структура базы меняется последовательными миграциями;
- доступ к данным сосредоточен в одном небольшом слое;
- правила расписания не зависят от особенностей SQLite;
- используются обычные таблицы, связи и стабильные идентификаторы;
- дату и местное время хранят и обрабатывают согласованно с часовым поясом школы;
- перенос прежних данных SQLite выполняется явно, со сверкой всех таблиц и сохранением исходного файла для отката.

Не требуются микросервисы, очереди, отдельный поисковый сервер или обязательная контейнерная инфраструктура. Нужны короткие инструкции запуска, резервного копирования и восстановления базы.

Пароль администратора хранится в виде стойкого хеша. Сервер проверяет право редактирования и все обязательные ограничения независимо от проверок в интерфейсе. Секреты не включаются в исходный код.

### Новые фичи перед пробной эксплуатацией — пожелания от 13.10.2026

**Встроенное руководство администратора — реализовано.** `/documentation` открывается из пункта «Документация» левой панели после сохранения черновика; прямой адрес проходит тот же вход администратора. Руководство начинается с подготовки данных школы после создания учётной записи. 21 раздел включает описание возможности, шаги и пример: настройки, справочники, календарь, звонки, планы, ручное и автоматическое составление, копирование, сокращённый день, подгруппы, объединение, недоступность и замены, возврат преподавателя, нагрузку, публикацию, публичные просмотры, печать, мероприятия, очистку и архив. Указан приоритет кабинета учителя и мягкий характер предпочтительных групп; жёсткий список разрешённых групп не описывается как готовая возможность. Содержание слева на компьютере и в раскрывающемся блоке на телефоне; есть переходы между разделами и к соответствующим административным страницам. Руководство не меняет данные и не создаёт новый режим начальной базы.

F8 реализована: печать расписания групп на А4 и сохранение в PDF. F5 реализована: опубликованное расписание учеников на главной. F6 реализована: общий набор предметов автоматически пополняется один раз, отдельный диалог убран. F7.1 реализована: заранее заданные значки предметов с общими переключателями показа для администратора и учеников; F7.2 реализована: значки основных действий с текстовыми подписями. F9 реализована: двухколоночная форма, поиск предпочтительных групп и число выбранных. Порядок работы задаёт таблица выше; номера F сохраняются при добавлении пожеланий. Функциональные изменения проверяются по отдельности, затем вместе на этапе 8. Этап 8 технически проверен на изолированных базах; далее — пользовательская приёмка в условиях школы и развитие по её замечаниям.

**F1. Страница «Нагрузка учителей» — реализовано, готово к просмотру.** Отдельный путь `/teacher-load`, доступный администратору; переход находится в разделе «Работа» левой панели. Перед переходом сохраняются правки редактора. Выбирается один месяц и год через компактный элемент с русской сеткой месяцев и редактируемым годом; фиксированного списка 2025–2027 больше нет. Год можно ввести вручную или переключить стрелками. Escape и клик снаружи закрывают выбор без изменения периода; повторный выбор текущего месяца не запускает загрузку заново. Таблица включает всех действующих преподавателей, в том числе с нулём уроков, и архивных с занятиями в выбранном месяце. По умолчанию сортируется по фамилии/ФИО по возрастанию. Доступны поиск и сортировка по каждой неделе или месячному итогу. Отдельных столбцов количества групп нет; группы и подгруппы видны в детализации занятий.

Каждая колонка недели показывает уроки и процент нагрузки, последняя — итог за месяц. Недели идут с понедельника по воскресенье, но в крайних колонках учитываются только даты выбранного месяца; такие колонки отмечены как части недели. Поэтому сумма недельных уроков равна месячному итогу. Нажатие на ячейку открывает занятия только её периода, а на ФИО — занятия месяца. Внизу диалога вместо списка занятий показана таблица по неделям: одна строка на неделю, семь столбцов Пн–Вс плюс даты недели. Недельная ячейка открывает одну строку, ФИО и месячный итог — все недели месяца, включая пустые. В ячейках — фактическое время начала, короткое название предмета из справочника, участники/подгруппы и кабинет; полное название доступно в подсказке и для программ чтения с экрана. Суббота и воскресенье не скрываются, записи в выходные показаны наравне с буднями. Даты за пределами выбранного месяца приглушены и не включают чужие занятия; названия неучебных недель и предупреждения неполной публикации сохранены. На узком экране таблица прокручивается горизонтально, даты недель закреплены. Отдельно суммируются минуты уроков. Учебный час в отчёте — один урок; сокращённый урок также считается одним. Общий урок нескольких групп считается один раз для преподавателя, включая случаи разных номеров урока у участников. Несвязанные занятия подгрупп остаются отдельными. Мероприятия показаны отдельно и не входят в процент предметной нагрузки. Имена сопоставляются по идентификаторам, поэтому однофамильцы не смешиваются.

Ориентир полной обычной учебной недели — 18 уроков = 100%. Для каждой учебной даты вклад в ориентир равен 18, делённым на число общих учебных дней недели в календаре школы. Учитываются границы четвертей и месяца, общие каникулы и неучебные дни; индивидуальные календари групп не меняют школьный ориентир. Общие явные учебные дни в выходные также учитываются. Месячный ориентир складывается из недельных; фиксированной нормы 72–78 уроков нет. Это расчётный показатель назначенных уроков, а не расчёт зарплаты или индивидуальной ставки преподавателя. База расчёта видна в подсказках и в детализации, месячная база — также в заголовке итоговой колонки. Процент округляется до одного десятичного знака, значения выше 100% сохраняются. Цвета чисел и индикаторов: менее 50% — красный; 50–79,9% — жёлтый; 80–99,9% — синий; 100% и выше — зелёный. Значения выше 100% выделяются дополнительно жирным в таблице и детализации; повышенная нагрузка сама по себе не считается ошибкой. Диапазоны описаны в легенде, числа сохраняются; отсутствие расчёта отмечается нейтральным цветом. Цвета не означают индивидуальную договорную норму преподавателя. Если период целиком неучебный, пустые ячейки показывают название из общего календаря школы, например «Осенние каникулы», вместо «0 уроков» и процента. Каникулы между четвертями также распознаются; обычные выходные в конце недели не мешают подписи каникул. Для обычной учебной недели без назначенных уроков остаётся нулевая нагрузка. Реальные занятия или мероприятия на неучебной неделе не скрываются; при нулевом календарном ориентире процент для фактических уроков показан как «—». Неизвестный неучебный промежуток не называется каникулами: используется «Нет учебных дней».

Можно отдельно выбрать сохранённый черновик или опубликованные данные; два источника не складываются. Кнопка «Обновить» загружает актуальные данные. Для публикаций используются снимки всех четвертей, пересекающих выбранный месяц, включая их собственные календари; видны версии и даты публикаций. При отсутствии части публикаций явно показано, что суммы за затронутые периоды неполные; их проценты не рассчитываются. Сбой загрузки не подменяет публикацию черновиком и не оставляет прежние суммы под новым месяцем. Страница прокручивается вертикально, несмотря на запрет общей прокрутки в редакторе; исключение действует только для `/teacher-load`. На телефоне фильтры располагаются вертикально, таблица прокручивается внутри собственного блока, а столбец ФИО остаётся видимым при горизонтальной прокрутке. Выбор месяца и года помещается в узкий экран. Проверены подсчёт, календарные ориентиры, сборка, поиск, сортировка, детализация, граница четвертей, отсутствие публикации, ошибки/повтор, смена источника во время загрузки и переходы в редактор.

**F2. Автоматический подбор замены при недоступности — реализовано, готово к просмотру.** Предпочтительные группы учителя уже реализованы; не создавать второй справочник закреплений вместо них. Уже есть подсветка затронутых занятий и одиночная/массовая замена на выбранного преподавателя. Реализована функция «Подобрать замены» для уроков недоступного учителя на выбранный период, с фильтром групп и предметов. Само сохранение больничного не меняет расписание: администратор запускает подбор, видит предложение и применяет его.

Подбирать преподавателей той же специальности, свободных и доступных на реальных интервалах, с проверкой требований к кабинету. Приоритет получают преподаватели с соответствующей предпочтительной группой; затем учитывать текущую нагрузку и дополнительные окна. Желательно сохранить одного заменяющего на предмет класса в пределах периода, но при нехватке ресурсов можно предложить разных с явной детализацией. Считать предложенные замены совместно, чтобы один кандидат не оказался назначен одновременно на несколько разных занятий. Общие уроки заменяются как единое занятие у всех участников. Неразрешённые уроки остаются отмеченными с причиной; допускается явное применение найденной части предложения, если список пропусков показан и согласован администратором. Применённая часть сохраняется одним действием с общей отменой и повторной серверной проверкой.

В «Справочники → Учителя → Недоступность» ограничения сохраняются кнопкой «Сохранить», без перехода к подбору. Затронутые уроки доступны через уведомление «Нужна замена» в расписании. Автоматический подбор открывается на странице `/teacher-replacements` для выбранного учителя и периода отсутствия. Диалог позволяет сузить даты, выбрать группу и предмет; фактические ограничения времени и дней недели выбранного правила сохраняются. Общие занятия показаны одной строкой со всеми группами. Неразрешённые строки содержат причины; для применения найденной части нужно явно отметить согласие оставить остальные уроки без изменений. Кабинеты и время автоматически не меняются. При выборе предпочтений учитываются группы, непрерывность преподавания по предмету, актуальная нагрузка и дополнительные промежутки больше 20 минут; это эвристика подбора, а не гарантия оптимального расписания. Уроки с меньшим числом кандидатов обрабатываются первыми.

Применение повторяет подбор и проверки на сервере, сохраняет все выбранные замены и временные назначения одной транзакцией. Кнопка «Отменить замены» доступна в диалоге после применения: отменяет всю операцию, пока после неё не менялась ревизия данных. Она возвращает точные исходные назначения и удаляет созданные этой операцией временные назначения; обычное сохранение по-прежнему запрещает новые назначения недоступного учителя. После последующих изменений отмена отклоняется без перезаписи правок. Повторы запросов с тем же идентификатором не применяют операцию дважды.

Для временной замены задаются начальная и конечная даты включительно; она не меняет постоянные предпочтения учителей. За пределами периода прежние назначения сохраняются. Если период заполнен позднее автосоставлением, учитываются принятые заменяющие для предмета класса/подгруппы и фактическая недоступность исходного преподавателя. Даты включаются с обеих сторон, при пересечении действует последнее подходящее принятое правило. Вне периода генератор возвращается к обычному подбору: временная замена не превращается в постоянное закрепление, а занятость исходного учителя допускает обычный подбор другого кандидата. Ручные сохранённые уроки сохраняются при соответствующем режиме генерации. Возврат учителя не должен слепо восстанавливать старую копию расписания и стирать последующие ручные изменения. Для постоянного изменения предложить передачу преподавания по F3 с выбором принимающего учителя; автоматический подбор может помочь выбрать кандидата. Безопасное применение и публикация остаются отдельными действиями.

**F3. Передача преподавания класса другому учителю — реализовано, готово к просмотру.** Сценарии: пришёл новый преподаватель и получает предмет целого класса от прежнего; нужно разгрузить учителя; временный заменяющий становится постоянным. В расписании группы выбрать предмет, исходного и нового преподавателя, при необходимости подгруппу, начальную дату и необязательную конечную дату. Передаётся преподавание выбранного предмета, а не все дисциплины класса. Обе заданные границы включаются. Без конечной даты правило действует дальше до явного изменения; существующие занятия меняются только в доступном диапазоне расписаний, будущая генерация использует новое назначение. Использовать существующие предпочтительные группы для обычного подбора; правило передачи с предметом и датами хранить отдельно только для обеспечения действия выбранного периода, не дублировать общий механизм предпочтений. Перед реализацией определить поведение пересекающихся правил и явного ручного выбора другого учителя. До применения показываются количество замен, даты, группы и конфликты; преподаватель должен подходить по предмету и быть свободен и доступен. Старые даты сохраняются, норма часов не меняется. Кабинеты проверяются, изменение кабинета показывается отдельно в предпросмотре.

Если выбранная запись — общий урок, нельзя поменять преподавателя только у одной группы, оставив прежнюю общую связь: предложить замену у всех участников либо явное разъединение. Замены и изменение назначения применяются согласованно одним действием с общей отменой в пределах текущей модели отмены. Новые конфликты блокируют всё применение, частичного молчаливого изменения нет. Редактирование черновика не меняет публичное расписание до повторной публикации. Правило без конечной даты должно корректно переживать переход между четвертями; не трактовать его как «только оставшаяся часть текущей четверти».

Реализована отдельная административная страница `/teacher-replacements` «Замены и переназначения». Переход находится в разделе «Работа» левой панели, перед переходом сохраняется черновик. Фильтры: четверть и предмет, необязательные учитель и несколько групп. Список групп вертикальный, с поиском и прокруткой примерно на 6–8 пунктов. Для преподавателя можно переключить просмотр текущих и заменённых занятий исходного учителя. Таблица содержит недели четверти, столбцы Пн–Вс и фактическое время, группы/подгруппы, преподавателя и кабинет каждого занятия. Общий урок показан одной карточкой.

Нажатие на занятие открывает разовую замену; на неделю — все занятия, попавшие под фильтры, при выбранной группе или учителе. Переназначение периода позволяет выбрать даты, всю четверть или отсутствие конечной даты. В списке преподавателей видны подходящие специальности и число доступных занятий; проверяется всё предложение совместно, включая пересечения внутри пакета. Результат предварительно показывается; пропуски требуют явного подтверждения. При частичной передаче правило для дальнейшего составления не создаётся для неполностью переданного потока, чтобы позже не изменить пропущенные уроки. При пересечении сохранённых назначений генератор использует последнее подходящее назначение, учитывает подгруппы, недоступность и правила замены назначенного преподавателя. Сохранённые вручную уроки остаются на месте в режиме сохранения существующих.

Дополнение F2: «Учитель вернулся» открывает предпросмотр возврата с фактической даты и выбором периода отсутствия. Связь каждого заменённого урока с исходным учителем сохраняется отдельно; она восстановлена и для ранее применённых F2 замен. Возврат собирает занятия у разных заменяющих, проверяет свободное время исходного преподавателя, сохраняет занятия до даты выхода и уже прошедшие дни, пропускает удалённые, перемещённые и вручную изменённые записи. Общие занятия возвращаются целиком. Одновременно ограничивается выбранная недоступность предыдущим днём и завершаются связанные с ней временные назначения; другие периоды отсутствия и независимые назначения не меняются. Новые уроки, созданные генератором по принятому правилу замены, также сохраняют исходного преподавателя.

В диалоге «Проверка перед изменением расписания» общий список «Назначить преподавателю» содержит только преподавателей с хотя бы одним доступным занятием. В колонке «Результат» у каждого урока есть отдельный выбор доступного преподавателя; общий выбор действует для строк без индивидуального назначения. Можно распределить уроки между несколькими преподавателями и применить их одной операцией с общей отменой. Доступность строк пересчитывается совместно после каждого выбора. «Оставить без изменений» явно пропускает строку; оставшиеся пропуски требуют подтверждения частичного применения. Зеркала общего урока назначаются вместе. При индивидуальном выборе правила повторного автосоставления ограничены конкретными датами. Если уроки одной группы, предмета и подгруппы в одну дату распределены неодинаково, соответствующее правило не создаётся, а ограничение показывается предупреждением; сами выбранные замены сохраняются в расписании.

При обычном окончании отсутствия замены ограничены включительным интервалом: занятия после конца периода остаются у исходного учителя, прежние заменённые занятия не переписываются. Досрочный выход выполняется действием «Учитель вернулся». Разовое ручное изменение учителя или заметки исключает существующую запись из автоматического возврата, и она показана как требующая проверки. Предпросмотр и применение повторяются на сервере с проверкой ревизии; расписание, недоступность и назначения меняются одной транзакцией. Общая отмена доступна в диалоге, пока после операции не менялись данные; сетевой повтор использует тот же идентификатор. Публикации не меняются до отдельной публикации.

**F4. Более удобное расписание учителя — F4.1–F4.2 реализованы, готовы к просмотру.** Автосоставление должно предпочитать занятия рядом друг с другом, учитывая существующие предпочтительные группы и правила F2–F3. Предпочтительная смена — необязательная настройка: без предпочтения (по умолчанию), первая или вторая. Не запрещать работу в обеих сменах: учитель может, например, работать с 11:00 до 19:00. Реальное разрешённое время определяется доступностью, а смена служит только дополнительным предпочтением. Смена группы определяется фактическим началом её учебного дня: до 12:00 или с 12:00, как в текущем публичном просмотре. Выбор смены учителя не переводит в неё группы и не меняет время их уроков.

Оценка окон идёт по реальным интервалам всех групп: два пятых урока разных смен не означают соседние занятия. Для измерения сначала показывать промежутки в минутах; обычные перемены не объявлять окнами, не выводить «4 окна» из разницы номеров. В F4.1 перерыв помечается, только если он длиннее большей из фактических перемен после предыдущего и перед следующим занятием учителя. Перемены берутся из соседних ячеек соответствующих групп на конкретную дату в публикации; при отсутствии соседней ячейки используется самая длинная общая перемена из опубликованных настроек звонков, для старых снимков — стандартные звонки. Для пересекающихся занятий сначала объединяются занятые интервалы, обычные перемены сравниваются только на границах этих блоков. Отображается вся длительность ожидания, а не превышение над переменой. Общие занятия и мероприятия учитываются; до первого и после последнего занятия ожидание не добавляется. На `/teachers` перерывы видны между карточками уроков, над таблицей — сумма за выбранную неделю и пояснение правила. Данные вычисляются из неизменного опубликованного снимка, правки черновика результат не меняют.

Сначала улучшать размещение новых занятий в подготовленных ячейках. Сохранённые вручную уроки и время групп автоматически не двигать; возможное отдельное действие улучшения готового расписания потребует собственного предпросмотра и отмены. Недоступность, пересечения, назначенный преподаватель, пригодность кабинетов и максимум семь уроков группы в день важнее уменьшения окон и предпочтения одной смены. Полное отсутствие окон не гарантируется. Показывать понятное сравнение результата по промежуткам и дням работы в обеих сменах, а также причины оставшегося недобора. Не улучшать удобство одного учителя ценой скрытого нарушения обязательных правил или резкого ухудшения равномерности нагрузки групп.

F4.2: предпочтительная смена сохраняется у учителя отдельно от групп; отсутствие значения означает «Без предпочтения», миграция 17 сохраняет этот режим для всех существующих записей. В выборе допустимого назначения генератор добавляет ограниченный мягкий приоритет уменьшения времени перерывов, избегания нового дня с обеими сменами и соответствия предпочтительной смене. Принятые назначения F2–F3 и предпочтительные группы сохраняют приоритет подбора. Расчёт использует индекс занятости конкретного учителя за конкретный день; при выборе кандидата полный график не обходится. Сравнение перед применением показывает текущий черновик и предложение за четверть для учителей, затронутых выбранными группами, включая их занятия в остальных группах: минуты и число длительных перерывов, дни работы в обеих сменах. Итоги дней суммируются по учителям; таблица «По учителям» раскрывает детали. При добавлении новых занятий показатели могут увеличиться, поэтому это сравнение расписаний, а не обещание улучшения всех показателей. Изменение сохранённых вручную занятий отдельно не реализуется в этом подэтапе.

**F5. Главная страница для учеников — реализовано, готово к просмотру.** По `/` сразу открывается опубликованное расписание учеников без входа, в том числе при действующем административном сеансе. Используется та же публичная страница, что и по `/students`; существующие ссылки, включая параметры `group`, `quarter`, `date` и завершающий слеш, продолжают работать. Выбор класса, четверти и даты сохраняется в адресе и после перезагрузки, последний класс запоминается. На главной есть переходы «Учителям» и «Администратору»; ссылка администратора ведёт через `/admin` в защищённый редактор `/schedule`, остальные административные пути и проверка авторизации сохранены. Бренд страницы учеников и ссылки для учеников из учительской страницы, формы входа и редактора ведут на `/`. При отсутствии публикации показывается «Расписание ещё не опубликовано», без подмены черновиком или формой входа. Главная обращается только к публичным API. Проверены главная и старый адрес, параметры и сохранённый класс, смена четверти, возврат браузером, вход и прямые ссылки восьми административных страниц, база без публикации и мобильные ссылки от 320 до 1440 пикселей.

**F6. Общий набор школьных предметов — реализован.** Стартовый набор из 25 предметов автоматически включается в общий справочник новой и существующей базы. Он охватывает русский язык, литературу, литературное чтение, математику, алгебру, геометрию, вероятность и статистику, английский/немецкий/французский/китайский языки, историю, обществознание, географию, физику, химию, биологию, окружающий мир, информатику, труд (технологию), изобразительное искусство, музыку, физическую культуру, основы безопасности и защиты Родины, основы религиозных культур и светской этики. Полные и короткие названия, цвета и требования к кабинетам заданы заранее; свои предметы можно добавлять вручную.

Отдельная кнопка и диалог «Готовые предметы» удалены. Однократная миграция добавляет только недостающие записи: устойчивый ID и точные нормализованные названия/известные сокращения учитывают регистр, пробелы, пунктуацию и ё/е. Существующие пользовательские, архивные и переименованные записи сохраняются со всеми настройками. Общие названия вроде «Иностранный язык» и составные предметы не подменяются и не мешают добавлению конкретных предметов. Если в действующей базе появились новые записи, версия черновика обновляется, чтобы старый открытый справочник не затёр пополнение. Уроки, планы, назначения и публикации не меняются. Впоследствии удалённые предметы не восстанавливаются при каждом запуске.

**F7. Значки предметов, кнопок и надписей. F7.1–F7.2 — реализованы, готовы к просмотру.** Добавить согласованные небольшие значки, где они помогают распознаванию: например, флаг Великобритании для английского и Германии для немецкого; книжные и другие предметные символы для остальных дисциплин. Значки предметов заданы заранее, отдельного выбора в форме предмета нет; для собственного неизвестного предмета используется общий значок. Отображение в расписании должно оставаться понятным на телефоне и без наведения: первоначально значок рядом с коротким названием, а замена текста одним значком — отдельный вариант для просмотра заказчиком. Полное название доступно в подсказке и для программ чтения с экрана. На кнопках сохраняются понятные подписи; не добавлять значки ко всем надписям без необходимости. Формат изображений выбрать по существующим компонентам, обязательная генерация PNG не требуется.

F7.1: 26 согласованных SVG-значков, включая общий значок книги и 25 предметных вариантов. В списках значки имеют размер 24 × 24 px. В карточках расписания учеников и редактора — 36 × 36 px слева; справа сверху название с фамилией учителя, ниже кабинет. Для подгрупп остаются отдельные строки учителей и кабинетов. Русский язык обозначается российским флагом, математика — знаками + − × ÷, ОРКСЭ — православным крестом, труд — молотком, физкультура — оранжевым баскетбольным мячом, история — стилизованным профилем Сталина. Они появляются рядом с названиями в онлайн-расписании учеников (главная и `/students`), в редакторе расписания и общем справочнике предметов. У предметов используются заранее заданные значки. Выбор и отключение значка из формы предмета удалены; при редактировании других полей сохранённый значок не меняется. Старые записи и опубликованные снимки получают автоматический вариант без переписывания истории. Значки декоративны для программ чтения с экрана; текст названия остаётся. Печатная форма сохраняет полные названия без значков. На странице «Настройки → Общие настройки» (`/display-settings`) доступны два независимых переключателя показа значков для администратора и учеников. Настройки общие для школы, сохраняются отдельно от расписания и не меняют его версию или публикации. Общий показ значков у учеников обновляется при открытии страницы, смене недели/группы и возврате во вкладку, без повторной публикации. По умолчанию оба переключателя включены. F7.2 реализована: общий компонент ActionLabel показывает контурные значки 14 × 14 px для добавления, редактирования, удаления, сохранения, печати, замены учителя, применения и предпросмотра. Значки добавлены к основным кнопкам справочников, календаря, планов, настроек, редактирования урока, переназначений, печати и диалогов операций расписания. Подписи, обработчики и состояния доступности кнопок сохранены. SVG декоративны, скрыты от программ чтения с экрана и не получают отдельный фокус. Не добавлены значки ко всем надписям или кнопкам отмены. Проверены формы и страницы на ширине 320–1440 px, сохранение предмета, диалог замены учителя, доступные имена и скрытие управления в режиме печати.

Общие настройки включают название школы (пустое или до 200 символов после удаления пробелов по краям). Ручное размещение, перенос, обмен, редактирование, мероприятия, изменение звонков и сокращённого дня, автосоставление и сервер запрещают новые пересечения. Неизменённое старое пересечение либо уменьшение его интервала сохраняется; новая дата, другой ресурс или усиление нарушения не наследуют допуск.

Замена запускается для одного урока из его карточки или для уроков с недоступным учителем во всех группах выбранной четверти через «Нужна замена». Администратор выбирает преподавателя и уроки; предпросмотр проверяет специальность, архив, доступность и занятость, включая уже выбранные замены. Допустимые уроки меняются одним действием, недопустимые пропускаются с пояснением. Все зеркала совместного урока меняются вместе. ID, предмет, время, кабинет, примечание и часы сохраняются. Ответственный мероприятия меняется в его карточке. Возврат к недоступному ресурсу отменой запрещён; предупреждение показывается перед заменой. Специальности в диалоге учителя получили увеличенный прокручиваемый блок.

**Просмотр 4.2б.2:** отметить больничный на один день, убедиться в сохранности уроков и часов; выполнить одиночную и массовую замену, проверить пропуски занятых преподавателей и связанные группы. Добавить повторяющийся ремонт кабинета на интервал, проверить границы времени и запрещённые новые назначения. Проверить сохранение правил после обычной правки справочника и перезапуска.

**Просмотр 4.2а:** попытаться занять одного учителя в двух группах, проверить красные ячейки, подсказку и блокировку; затем выполнить подтверждённый перенос и проверить, что обычное занятие удаляется вместе с назначением нового. Проверить, что общее занятие/мероприятие не удаляется переносом.

**Просмотр 4.2б:** разместить три группы в двух кабинетах информатики, поставить лабораторную в обычный кабинет, создать новое пересечение кабинета изменением времени; убедиться, что старые конфликты можно оставить без усиления и непересекающееся использование разрешено.

Проверить два параллельных занятия разных подгрупп с разными учителями и кабинетами. Затем попробовать поставить в тот же интервал занятие всей группы: оно должно быть запрещено. Убедиться, что часы подгрупп считаются отдельно и общий урок добавляет каждой по одному часу.

**4.3. Часы.** Добавить живые счётчики и общую таблицу недобора. Пересчитывать после каждого изменения и смены плана.

**Просмотр:** поставить и удалить физику, перенести её на другую неделю той же четверти; проверить изменение счётчика при добавлении и удалении и сохранение суммы при переносе. Переключить четверть и убедиться, что её часы считаются отдельно. Перенос за границы выбранной четверти не допускается.

**Результат этапа:** можно вручную составить и сохранить корректное расписание нескольких групп с контролем часов.

### Этап 5. Работа с несколькими неделями

**5.0. Обмен уроками — реализовано.** Два обычных одиночных урока всей группы можно обменять внутри дня, между днями и неделями одной четверти. Оба исходных места освобождаются для проверки; занятость преподавателей и кабинетов проверяется по реальному времени для обоих новых назначений. Время ячеек сохраняется, предмет, учитель, кабинет, ID и примечание перемещаются вместе с уроком. При конфликте обмен не применяется. Сохранение и отмена действуют на оба урока сразу. Чтобы открыть другую неделю во время перетаскивания, нужно задержать урок над её датой в нижней полоске. Подгруппы, совместные уроки и мероприятия пока не обмениваются.

**5.1. Копирование и повторение — реализовано, готово к просмотру.** «Копировать неделю» находится рядом с переключением недель текущей группы; «Повторить урок» — в карточке обычного или совместного занятия. Выбираются другие недели той же четверти. Предпросмотр показывает добавления, пропуски с причинами и изменение часов по предметам, видам занятия и подгруппам; превышение плана показано, но не блокирует ручное действие.

Копия занимает тот же день недели и номер ячейки, используя время и длительность назначения. Сохраняются предмет, вид занятия, учитель, кабинет, подгруппа и примечание. Каждая копия получает новый ID. Настройки времени, звонков, перемен и все старые занятия остаются прежними; новые ячейки не создаются. Выходные, каникулы, даты вне четверти, отсутствующие позиции, занятые участники, учителя или кабинеты, интервалы недоступности, неподходящие помещения, архивные или неразрешённые справочные связи и отсутствие подходящего плана дают пропуск. Копирование не подбирает другого учителя или кабинет вместо явно сохранённых в источнике.

Совместные уроки и мероприятия копируются со всеми связанными группами как один блок с новой общей связью для каждой недели. Если день, позиция, время или обязательное ограничение не подходит хотя бы одному участнику, пропускается весь блок. Обычные занятия разных подгрупп могут дополнять свободные подгруппы в ячейке. Предпросмотр не изменяет расписание; применение и отмена выполняются одним массовым действием через общее сохранение и серверные проверки. Повторное применение не создаёт дубликатов в занятых местах.

**Просмотр:** скопировать обычную неделю на сокращённую, на неделю с каникулами и в частично заполненную неделю. Убедиться, что существующие занятия не исчезли.

**5.2. Изменение календаря после заполнения.** Предварительный просмотр затронутых дат/групп, подтверждение снятия занятий и пересчёт часов для новых каникул реализованы в 3.1. Для изменения звонков согласованное применение остаётся частью 3.2.

**Просмотр:** добавить каникулы на заполненную неделю, сначала отменить операцию, затем подтвердить снятие занятий. Отдельно попробовать изменение времени с конфликтом.

**Результат этапа:** расписание четверти быстро заполняется и допускает различия недель без скрытого повреждения данных.

### Этап 6. Общие занятия и мероприятия

**6.1. Мероприятия.** Реализовать выбор групп, места, времени и ответственных; замену затронутых уроков с предварительным просмотром.

**Просмотр:** поставить линейку для нескольких групп в актовом зале вместо первого урока и проверить уменьшение часов заменённых предметов.

**6.2. Объединённые уроки — реализовано, готово к просмотру.** «Объединить группы» в карточке академического урока всей группы создаёт или расширяет общее занятие. Участники существующего исходного занятия закреплены; выбираются дополнительные разрешённые группы с планом того же предмета и вида занятия, общий учитель, кабинет и одинаковые время/длительность. Для добавляемой группы используется уже поставленный совместимый одиночный урок или свободная ячейка на выбранное время. При явном изменении времени можно использовать ячейку прежнего времени исходного урока, если новое время помещается в сетку. Новые позиции не создаются, другие уроки не сдвигаются. Подгруппы, мероприятия, другой предмет и чужое общее занятие не поглощаются.

Предпросмотр показывает объединение существующих записей и добавление нового участника, сумму учеников, кабинет, конфликты и часы каждой группы до/после. При объединении часы существующих участников не увеличиваются; пустая целевая ячейка получает один урок. ID и индивидуальные примечания сохраняются. Кабинет автоматически выбирается по единому приоритету учителя и групп с проверкой общего числа участников, типа, занятости и недоступности; можно выбрать явно. Применение и отмена — единое действие, сервер повторяет ограничения. Если отмена вернула бы старое нарушение, диалог предупреждает о её запрете. Удаление общего урока требует подтверждения со списком групп и удаляет все зеркала.

**Просмотр:** объединить две группы, проверить вместимость, отображение у обеих групп и предупреждение при удалении общего занятия.

**Результат этапа:** общие события не создают фиктивных конфликтов и не дублируют занятость кабинета.

### Этап 7. Публикация и просмотр

**7.1. Публикация.** Реализовать проверку всей четверти, итог изменений и согласованный опубликованный снимок. Повторная публикация заменяет предыдущий снимок только после успешной проверки и сохранения.

**Просмотр:** опубликовать неделю, изменить черновик и убедиться, что читатели видят прежний вариант до следующей публикации.

**7.2. Экран ученика.** Отдельная страница с поиском группы, ближайшей неделей, переходами назад/вперёд, датой, четвертью, каникулами и удобным отображением на телефоне. Показать все подгруппы и их места занятий.

**Просмотр:** найти вчерашний урок, следующую неделю и расписание после каникул.

**7.3. Экран учителя.** Отдельная страница с поиском по фамилии, выбором преподавателя среди однофамильцев, его занятиями групп и подгрупп, заметными кабинетами и сортировкой по времени начала, затем по номеру урока.

**Просмотр:** проверить неделю преподавателя, который работает с несколькими группами и разным фактическим началом дня.

**Результат этапа:** первая пригодная для повседневного использования версия с ручным составлением расписания.

### Этап 9. Автоматическое распределение (исторический номер; базовая версия реализована)

Статус: первый вариант реализован раньше календарных подэтапов по запросу заказчика и готов к просмотру. Доступен в левой панели «Автосоставление»: выбор групп, расчёт на всю выбранную четверть, просмотр и применение предложения. Фильтры отдельных дат и предметов остаются возможным расширением. Генератор не считается следующим обязательным заключительным этапом; новые возможности добавляются по результатам использования.

Кнопка «Распределить автоматически» заполняет свободные ячейки в выбранном диапазоне дат для одной или нескольких групп. Использует оставшиеся часы и все обязательные ограничения. Уже поставленные вручную занятия сохраняет, если включён флажок сохранения заполнения; при отключении сначала очищает выбранные группы в копии расписания, затем предлагает новое заполнение.

Перед запуском выбираются группы, даты и предметы. Результат сначала показывается как предложение: добавленные занятия, оставшиеся часы, причины неудачи. Применение сохраняет весь принятый результат в черновик; публикация остаётся отдельным действием.

Начальная реализация может использовать простой подбор доступных мест с предпочтением равномерного распределения по неделям и дням. Она не гарантирует нахождение решения даже тогда, когда оно существует. Сообщение «не удалось распределить» не должно называться доказательством невозможности.

**Просмотр:** сравнить предложенное расписание с ручным, изменить часть занятий, повторить распределение для оставшихся часов. При недостатке кабинетов получить понятный отчёт, а не конфликтное расписание.

**Результат этапа:** помощник заполнения. Усложнение алгоритма допускается только по конкретным замечаниям к его результатам.

## 13. Минимальная проверка качества

На каждом этапе — короткая ручная проверка нового сценария и стандартная проверка сборки. Не создавать отдельные тесты на каждую кнопку и каждую строку справочника.

Небольшой автоматический набор покрывает самые дорогие ошибки:

1. Пересечения реальных интервалов для группы, учителя и кабинета, включая разное начало дня, сокращённые уроки и смежные интервалы без пересечения; параллельные подгруппы и конфликт подгруппы с целой группой.
2. Подсчёт часов при удалении, копировании, сокращённом уроке, общем занятии и замене урока мероприятием; отдельные планы подгрупп без удвоения часов.
3. Применение календаря и времени: каникулы, индивидуальное исключение, сокращённый день с сохранением дневного начала, сдвиг одного урока или всего дня и выбор времени при копировании. Локальная правка перемены сдвигает последующие уроки только выбранного дня группы и не изменяет глобальные настройки.
4. Запрет серверного изменения без входа и отсутствие утечки черновика в опубликованное расписание.
5. Сохранение массовой операции целиком и отсутствие дубликатов при повторе запроса.

Эти проверки добавляются вместе с соответствующим функционалом. Полный браузерный прогон всей системы после каждого небольшого изменения не требуется. Мобильный вид и удобство заполнения проверяются глазами на ключевых этапах.

## 14. Пример для демонстраций

Использовать вымышленные данные: группы 5А, 5Б и 6А, обычные кабинеты, два кабинета информатики, лаборатория физики и актовый зал. Для одной группы задать начало занятий с 14:00 без настройки смены. Завести нескольких преподавателей, в том числе трёх учителей одного предмета, чтобы проверить поиск и постоянные назначения; один преподаватель должен иметь утренние и дневные занятия.

Подготовить четверть с обычной неделей, отличающейся от неё второй неделей, сокращённым днём, каникулами, общим мероприятием и намеренным недобором часов. Демонстрационные записи должны легко отличаться от рабочих; их загрузка не должна перезаписывать существующую базу.

Группу 5А разделить на 5А/1 и 5А/2. Добавить параллельные занятия информатики с разными учителями и кабинетами, общий урок всей группы и разный недобор часов двух подгрупп. В просмотре ученика должны быть видны обе подгруппы, а в просмотре преподавателя — только его занятия.

## 15. Решения для обсуждения при первом просмотре

1. Проверить на примере, достаточно ли одного постоянного разбиения группы или по предметам состав подгрупп различается; это влияет на модель участников и уточняется до хранения.
2. Настроить учебные дни, обычное начало занятий, длительности перемен и число ячеек по умолчанию.
3. Оценить предложенную область публикации — вся школа на четверть одним действием. Сам режим черновика и публикации уже подтверждён.
4. Уточнить, какие ограничения времени преподавателей реально нужны в первой версии.
5. Подтвердить необходимость строгой проверки вместимости.

Эти вопросы не мешают начать с визуального макета. Решения, влияющие на данные и правила, фиксируются до соответствующего этапа реализации.

Интерфейс содержит переключатель четвертей; текущая дата не блокирует ввод прошлых уроков.


## Уточнение после подэтапа 2.3: предметы преподавателя и замены

- В справочнике учителя задаётся список предметов, которые он ведёт. У одного учителя может быть несколько предметов; у предмета — несколько учителей. Пустой список допустим, но такой учитель не предлагается для новых уроков.
- В плане группы задаются только часы. Преподаватель и кабинет определяются конкретным уроком расписания.
- При выборе предмета в расписании показываются все его действующие преподаватели. Все подходящие преподаватели расположены по алфавиту и доступны для перетаскивания и размещения нажатием. Часы общие для назначения и не умножаются на число учителей.
- Для замены заболевшего учителя администратору достаточно открыть урок и выбрать другого преподавателя этого предмета. Дата, время, кабинет, подгруппа, вид занятия и сам урок сохраняются; норма часов плана не меняется. Можно также удалить урок и поставить карточку с другим преподавателем.
- В диалоге архивирования доступна кнопка «Удалить» с подтверждением окончательного удаления. У архивных записей она находится в редактировании. Удаление разрешается только без ссылок из всех уроков (прошлых и будущих), планов, учебных сеток, других записей справочников, настроек школы, опубликованного расписания и истории замен. Причина блокировки показывается через i; сервер самостоятельно проверяет ссылки, версию и повтор запроса. Последняя активная группа сохраняется.
- При изменении специальностей и архивировании история уроков и планы не переписываются. В существующем уроке можно оставить прежнего преподавателя. Новые назначения требуют подходящей действующей специальности.
- При обновлении приложения связи предметов с учителями переносятся из существующих планов и уроков. Проверка одновременной занятости преподавателей остаётся частью этапа 4.


## Уточнение после подэтапа 2.3: кабинеты и компактность

- Ни группа, ни учитель не обязаны постоянно находиться в одном кабинете. У преподавателя можно необязательно указать кабинет по умолчанию. Это подсказка, а не ограничение; фактически занятый кабинет сохраняется у урока.
- Порядок автоматической подстановки: кабинет преподавателя → основной кабинет группы. Перед расстановкой можно вручную выбрать кабинет над карточками преподавателей, а затем поменять его в самом уроке. При замене преподавателя существующего урока кабинет сохраняется до отдельной ручной правки.
- Уже реализована часть этапа 4.2: проверка занятости кабинета во всех группах и подгруппах по дате и фактическому времени. Проверяется добавление, перенос, редактирование кабинета, времени и сдвиг следующих уроков; проверка повторяется сервером. Окончание одного урока в момент начала другого допускается. Занятый кабинет помечается в форме и недоступен для нового назначения.
- Существующие пересечения после обновления не удаляются и не мешают несвязанным правкам; допускается сохранить их без увеличения либо уменьшить. Новые пересечения запрещены. Старые записи общего мероприятия сохраняются; полноценная сущность совместного мероприятия нескольких групп будет реализована отдельно. Старый текстовый кабинет без связи со справочником пока не участвует в проверке занятости.
- Классный руководитель отображается в верхней полоске информации о группе рядом с четвертью; полное ФИО доступно в подсказке. Нижняя легенда «Свободная ячейка / Подгруппы — отдельными карточками / Что можно проверить» убрана.
- В плане четверти и карточках не выводится повторяющаяся надпись «Вся группа»; имя участника показывается только для подгруппы. Страница плана группы уплотнена: меньше повторяющихся строк и действий, лабораторные помечены компактно. В форме выбора режима вариант «Вся группа» остаётся, чтобы отличать его от подгрупп.


## Уточнение 10.10.2026: план только с часами и автосоставление

- План группы не связывает предмет с преподавателем или кабинетом. У назначения сохраняются только участники и часы. Урок расписания хранит конкретных учителя и помещение. При обновлении удаляются прежние связи плана; нормы, подгруппы, ID назначений и все уроки сохраняются.
- Специальности в форме преподавателя выводятся одним алфавитным списком сверху вниз. Во всех диалогах добавления справочников курсор устанавливается в поле названия/ФИО, естественный порядок Tab проходит через поля к «Сохранить», затем к «Отмена».
- Единый приоритет кабинетов при ручном добавлении в режиме «Автоматически» и автосоставлении: кабинет конкретного учителя, основной кабинет группы, отмеченные кабинеты группы, остальные подходящие свободные помещения. Основной кабинет группы необязателен; классное руководство на выбор помещения не влияет. Список отмеченных кабинетов не ограничен, начальная рекомендация — 2–4 ближайших. Тип, известная вместимость, занятость и недоступность остаются обязательными проверками; для общего занятия учитывается сумма участников. Кабинет учителя или основной кабинет группы не считается размещением вне предпочтений. Изменение настроек не переносит сохранённые уроки.
- Требования к типу кабинета находятся у предмета: отдельно для обычных и лабораторных занятий. Генератор проверяет тип, известную вместимость, специальности учителей, реальную занятость кабинетов, учителей и участников, границы четверти и отмеченные неучебные дни. Ручная проверка типов и вместимости реализована в 4.2б.1.
- Генератор заполняет существующие свободные ячейки, не меняя время и ручные уроки; учитывает оставшиеся фактические часы. Результат — предложение со списком уроков, остатком и причинами, количеством уроков вне предпочтительных кабинетов. Сохранение происходит только по команде «Применить в черновик»; действие можно отменить до перезагрузки страницы.
- Первая версия использует простой подбор с распределением по дням и неделям. Оптимальное решение и полное заполнение не гарантируются; отдельные нормы нагрузки будут добавляться по этапам; интервалы недоступности преподавателей и кабинетов уже учитываются. Повторный расчёт дополняет только оставшиеся часы. Текущие календарные данные и время ячеек нужно подготовить до запуска.


## Уточнение 10.10.2026: очистка, перезапись и общие занятия

- В левой панели доступна очистка текущей недели или выбранной четверти. Текущая группа отмечена по умолчанию; можно выбрать несколько или все активные группы. Перед применением показано количество удаляемых занятий. Очищаются уроки и мероприятия, сохраняются сетка времени, перемены и каникулы. Неотмеченные группы и другие даты не меняются.
- Автосоставление по умолчанию сохраняет заполнение. Если отключить этот флажок, расчёт начинается с очищенной копии выбранных групп в пределах четверти. Удаления и результат сначала показываются в предложении; одна операция применения сохраняет всё в черновик. При отсутствии добавленных уроков отдельно предупреждается, что применение только очистит занятия.
- Генератор предпочитает равномерную нагрузку предмета по неделям и дням, соседние ячейки и заполнение окон. Для каждого участника добавляет не больше двух уроков одного предмета в день, считая обычные и лабораторные вместе. Существующие ручные превышения в режиме сохранения не удаляются. При нехватке ресурсов показывает оставшиеся часы; отсутствие окон и оптимальность не гарантируются.
- У предмета появился флажок «Объединять группы одной параллели». Параллель определяется номером в начале названия (5А и 5Б — одна, 6А — другая); без номера автоматического объединения нет. У исходной Физкультуры флажок включён. Генератор позволяет нескольким группам присоединяться к подходящему новому общему уроку при одинаковой дате, времени и длительности, свободных ресурсах и достаточной суммарной вместимости. Разные смены не сдвигаются автоматически ради объединения.
- Карточка «Мероприятие» доступна слева вне учебного плана. Для мероприятия обязательно свободное название до 200 символов: например, линейка, поход в библиотеку, музей, театр, классный час или родительское собрание. Дата и начало берутся из выбранной ячейки и не редактируются в этом диалоге. Можно изменить длительность, группы, необязательного ответственного и помещение. Сохранённые ранее линейки и классные часы сохраняют своё название. Мероприятие не входит в предметные часы; по умолчанию оно не вытесняет занятые ячейки. Для замены уроков либо сохранения их остатка применяются явно включаемые режимы из раздела 7.4. Ошибка отменяет всю операцию.
- Общее занятие хранит идентификатор связи, а у каждой группы — отдельную запись для её расписания и подсчёта часов. Совпадающие связанные записи занимают кабинет и учителя один раз. Проверяются участники, одинаковые ресурсы и интервалы, вместимость; чужое несвязанное занятие остаётся конфликтом. Редактирование общей карточки действует на всех участников; удаление снимает только запись текущей группы, при единственном оставшемся участнике связь объединения снимается. Очистка выбранных групп удаляет только их записи, сохраняя занятие у остальных.
- Изменения времени через звонки не могут рассинхронизировать общее занятие. Его время меняется через карточку сразу для всех групп. Независимое перетаскивание одной копии отключено.

## Уточнение 10.10.2026: предпочтения учителей и лимиты общего урока

- У преподавателя задаются предпочтительные группы. При автосоставлении подходящий свободный преподаватель с таким предпочтением имеет приоритет; если назначить его невозможно, разрешён другой преподаватель нужной специальности. Предпочтение не запрещает ручные назначения.
- У предмета с объединением групп одной параллели задаётся максимальное число групп в одном общем уроке: по умолчанию 2, допустимо 2–50. Лимит действует для конкретного занятия с одним учителем в одном помещении. Другой зал и другой преподаватель могут проводить независимое занятие одновременно. На служебные мероприятия лимит предмета не распространяется.
- Подгруппам при автосоставлении нужны кабинеты подходящего типа. При отсутствии таких помещений причина прямо указывает требуемый тип и предлагает проверить справочник. Название кабинета само по себе не определяет его тип.
- В левой панели и карточках выбора занятий выводится короткое название предмета из справочника; полное показывается при наведении. Поиск учитывает обе формы.
- В диалоге плана четверти точное выполнение нормы выделяется зелёным, недобор до 30% включительно — жёлтым, больший недобор и превышение — красным. Числа и текст сохраняются, чтобы смысл не зависел только от цвета.
- Виды кабинетов пока представлены фиксированным списком. Редактируемый справочник видов и переходы из обычного кабинета в лабораторию отложены. Пока один урок резервирует одно помещение на весь интервал.

## Общий набор предметов и значки

Пожелания включены в план перед пробной эксплуатацией как F6 и F7 (раздел 12). F6 и F7.1–F7.2 реализованы. Актуальные требования к каталогу, безопасному добавлению в существующую базу и читаемости значков описаны там; прежнее обязательное использование PNG и замена названия одним значком не считаются утверждёнными ограничениями.


## Уточнение 10.10.2026: единые учебные планы и левая панель

- Учебный план — именованный набор предметов и часов на четверть. Название уникально в четверти. План можно оставить без назначенных групп, назначить одной или нескольким группам. У группы в одной четверти один назначенный план. Отдельной сущности или страницы «индивидуальный план» в интерфейсе нет.
- Администратор сначала создаёт план и заполняет часы, затем назначает группы. Для небольших отличий создаёт копию выбранного плана, меняет предметы или нормы и назначает другим группам. Копия не наследует назначения и не меняет исходный план. Сохраняется команда создания плана из плана группы.
- Для предмета выбираются вид занятия и режим «Вся группа / По подгруппам». Часы задаются одним числом. В режиме подгрупп это норма КАЖДОЙ активной подгруппе назначенной группы, например по 18 часов. Число и названия подгрупп берутся из справочника автоматически, ручного сопоставления нет. Группы могут иметь разное количество подгрупп; если у группы их нет, назначение подгруппного плана требует сначала добавить подгруппы.
- Учителя и кабинеты задаются в расписании. Отдельные назначения подгрупп и их фактические счётчики сохраняются: норматив одинаковый, выполненные часы могут различаться.
- Существующие планы групп становятся обычными именованными планами, назначенными одной группе. Автоматического слияния между группами нет. Миграция сохраняет прежние уроки, время и рассчитанные назначения. Существующие именованные планы сохраняют названия и назначения.
- Сохранение плана обновляет нормы всех назначенных групп одной операцией. Замена плана при новом назначении группе требует подтверждения. Расставленные уроки, время, перемены и календарь не меняются.
- При удалении плана или снятии назначения последние нормы группы сохраняются в отдельной именованной копии в том же списке. Создание и редактирование четвертей находится в учебном календаре рядом с каникулами и графиком учебных дней. На странице планов остаётся только выбор четверти.
- Меню «Действия» заменено узкой постоянной панелью слева с видимыми значками. Наведение раскрывает подписи, кнопка сверху закрепляет панель; на сенсорном экране она открывается нажатием. Раскрытие не сдвигает сетку расписания. В панель перенесены учебные планы, справочники, календарь и действия расписания.


## Уточнение: отзывчивое автосоставление и учёт четверти

Автосоставление выполняется в отдельном потоке браузера (Web Worker). Показываются этап и процент расчёта, отмена завершает поток без применения частичного предложения. Оптимизированы повторные списки кабинетов и индексы нагрузки; расчёт по-прежнему заполняет всю четверть выбранных групп. После очистки одной недели новые уроки могут попасть и в другие свободные недели, а недобор считается по четверти, предмету, виду занятия и подгруппе. Перебор часов в таблице четверти отмечается зелёным и подписью «(перебор)».

Автосоставление ограничивает нагрузку группы семью занятыми ячейками в день, включая мероприятия. Параллельные занятия подгрупп в одной ячейке учитываются один раз. Лимит проверяется как при добавлении, так и при переносе урока для объединения групп; сохранённые ручные превышения не удаляются и не увеличиваются. Распределение общей нагрузки по дням и неделям — мягкое предпочтение с поправкой на доступную ёмкость учебного календаря (неполные недели, праздники, короткая сетка). Приоритет кабинетов и учителей, проверки занятости и нормы часов сохраняются. Если лимит или ресурсы мешают закрыть план, часы остаются в списке недобора, восьмой урок автоматически не добавляется.


Автосоставление содержит включённый по умолчанию флажок «Объединять уроки параллельных классов». При выключении новые объединения не создаются ни при расстановке, ни после неё; требования общей вместимости для будущего объединения не влияют на выбор обычного кабинета. Сохранённые общие уроки остаются в режиме дополнения. При включении используются разрешения предметов, время, вместимость и обычные проверки ресурсов; сам флажок не разрешает объединять неподходящие группы.


## Реализация 7.1: публикация четверти

«Опубликовать» в левой панели сначала завершает сохранение черновика, затем показывает проверку всех групп выбранной четверти. Предпросмотр сравнивает занятия, их ресурсы и фактическое время с последней публикацией; отображаются затронутые группы, ошибки и предупреждения. Пересечения ресурсов, недоступность, неподходящие кабинеты, нарушения совместных занятий и некорректные ссылки блокируют публикацию, включая унаследованные нарушения. Недобор, перебор часов и пустая четверть — предупреждения.

Сервер публикует собственное сохранённое состояние по проверенной версии черновика; снимок всех групп и результат повторяемого запроса записываются одной транзакцией. Публикация не изменяет черновик и его версию. В SQLite хранится последняя публикация каждой четверти с датой, автором и номером версии. Снимок содержит расписание четверти, фактическое время, справочники, календарь, звонки и планы; последующие изменения черновика его не меняют. Повтор запроса после сетевого сбоя возвращает результат той же операции, конфликт версий требует обновить проверку. Полный снимок защищён входом администратора; страница ученика использует ограниченное публичное представление опубликованных данных.

## Реализация 7.2: страница ученика

Статус: реализована, готова к просмотру по `/students` без авторизации. Доступны поиск класса, опубликованные четверти, выбор недели и даты, переходы назад/вперёд и «Сегодня». Последний класс хранится локально, текущий выбор отражается в адресе для передачи ссылки. Автоматический выбор открывает текущую учебную неделю или ближайшую опубликованную неделю с занятиями; ручной выбор позволяет вернуться к прошлым датам.

Показаны номера уроков, фактическое время начала в 24-часовом формате, предметы и мероприятия, фамилии учителей, кабинеты без слова «кабинет», все подгруппы и участники общих уроков. Подгруппы обозначены компактно: `6А/1 (Демидов)`. На широком экране одинаковые номера уроков выровнены по строкам; пустые места между занятиями сохраняют порядок, строки после последнего урока каждого дня скрыты, одновременные подгруппы находятся в общей строке урока. На телефоне компактные дни расположены вертикально. Каникулы, неучебные дни, отсутствие занятий у класса и отсутствие публикации различаются. Страница не загружает административную сессию или черновик.

Анонимные GET `/api/public/students` и `/api/public/students/schedule?quarterId=…&groupId=…` читают только опубликованные снимки. Сервер явно выбирает разрешённые поля: административные примечания, численность групп, планы и причины недоступности не возвращаются. Проекция кешируется по версии публикации и обновляется после новой публикации. Редактирование черновика не меняет публичный просмотр.

## Реализация 7.3: страница учителя

Статус: реализована, готова к просмотру по `/teachers` без авторизации. Поиск показывает полное ФИО; выбор связан с идентификатором преподавателя в опубликованном справочнике. Доступны четверть, неделя, дата, переходы назад/вперёд и «Сегодня». Последний преподаватель хранится отдельно от выбранного класса ученической страницы, текущий выбор отражается в адресе.

По уточнению заказчика, на странице занятия всех классов и подгрупп упорядочены по времени начала, затем по номеру урока. Номера первой смены синие, второй — коричневые. Цвет зависит от начала первого слота опубликованного учебного дня группы: до 12:00 — первая смена, с 12:00 — вторая. Время самого занятия не меняет цвет смены; например, пятый урок первой смены в 12:15 остаётся синим. У общих занятий номера участников сохраняют собственные цвета, если группы относятся к разным сменам. Подсчёт окон пока отложен. В компактных карточках показаны номер урока, только время начала, предмет, классы/подгруппы и заметный кабинет. Общий урок или мероприятие показаны один раз с перечислением участников. Каникулы не выводятся для всего преподавателя только на основании каникул одного класса. На телефоне дни идут компактными вертикальными карточками.

Анонимные GET `/api/public/teachers` и `/api/public/teachers/schedule?quarterId=…&teacherId=…` читают только опубликованные снимки. Ответ формируется по списку разрешённых полей, без административных примечаний, учебных планов, размеров классов и причин недоступности. Изменение черновика не меняет просмотр; новая публикация обновляет публичную проекцию. Полные снимки и изменения по-прежнему требуют административной авторизации.


### Уточнение: часы выбранным языковым подгруппам

В строке учебного плана можно назначить часы всей группе либо выбранным подгруппам каждой прикреплённой группы. Например, английский — всему 5А, немецкий — 5А/1, китайский — 5А/2. Количество часов применяется отдельно к каждой выбранной подгруппе. Старые строки без явного выбора сохраняют назначение всем активным подгруппам; импорт плана группы сохраняет уже заданный состав. Сохранение плана не переназначает существующие уроки.
