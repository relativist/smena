# Переход к загрузке нужных данных

Дата: 14 октября 2026 года. Проверочная база: 74 группы, 131 преподаватель,
181 323 урока за сентябрь 2024 — декабрь 2026.

## Причина

До перехода любой административный маршрут получал `/api/state`: около 60 МБ,
включая все уроки, планы и историю. Ручное сохранение отправляло около 56 МБ и
перезаписывало таблицы расписания. Выбор карточки преподавателя проверял места
по всей истории и занимал примерно 5 секунд в браузере.

Исходные измерения: `schedule-performance-analysis-2026-10-14.json`.

## Первый этап: ручной редактор

- `/api/editor/bootstrap`: справочники, четверти, календарь, общие настройки и
  версия черновика. Без уроков, всех планов и истории замен.
- `/api/editor/week`: рабочий диапазон выбранной недели. На первом этапе он
  содержит дни всех групп на этих датах: это сохраняет работу существующих
  форм и проверок объединённых уроков. Планы и итоговые счётчики — только для
  выбранной группы и четверти. Данные других недель не загружаются постоянно.
- `/api/editor/preview`: один запрос для подсветки всех мест выбранной недели.
  Сервер проверяет фактическое время, преподавателя, кабинет, недоступность,
  подгруппы и возможность обмена уроками.
- `/api/editor/days`: сохранение только изменённых дней. Сервер заново читает
  все группы на затронутых датах, проверяет изменения и сохраняет их одной
  транзакцией. Незатронутые строки не перезаписываются.
- Версия черновика защищает от перезаписи другой вкладки. Повтор запроса с тем
  же идентификатором возвращает прежний результат. Отмена использует обратное
  изменение дней, а не копию всего школьного расписания.
- На первом этапе массовые операции получали полный снимок при открытии
  соответствующего диалога. На следующем этапе этот путь заменён серверными командами.
- Документация и общие настройки используют только лёгкую загрузку.

История ручной отмены ограничена текущей рабочей областью и сбрасывается после
загрузки другой группы/недели или завершения массового действия. Перенос через
границу недель можно отменить до следующего переключения области. Долговременная
отмена массовых операций потребует отдельной серверной истории команд.

## Проверка первого этапа

Результаты: `scoped-editor-performance-2026-10-14.json`.

| Измерение | До | После |
| --- | --- | --- |
| Загружаемые данные редактора | 60,3 МБ | стартовые данные 94 КБ + неделя примерно 752–756 КБ |
| Выбор карточки преподавателя в браузере | около 5 с | 179–220 мс |
| Запрос сохранения при добавлении урока | около 56 МБ | около 2,4 КБ |
| Серверная проверка мест | вычислялась в браузере по всей истории | 63–66 мс, медиана пяти локальных запросов |
| Серверное сохранение изменённого дня | переписывалось всё расписание | примерно 65 мс |

Это локальные измерения на копии базы, а не оценка слабого сервера или сети.
Время от нажатия до «Сохранено» в браузере составляет примерно 0,5–0,6 с и
включает задержку автосохранения 350 мс.

Проверены добавление нажатием на зелёный фон, отмена, перенос и отмена между
неделями, сохранение счётчиков четверти, открытие/закрытие массового диалога,
переходы к документации и настройкам. Все 40 проверенных счётчиков назначений
совпали с расчётом по полному расписанию, включая подгруппы.

`npm test`: 287 тестов прошли; `npm run build` прошёл. Незатронутые строки дней
и опубликованные снимки не меняются. Рабочая база сохранила версию 359,
181 323 урока и 10 публикаций; изменения схемы добавляют индексы и таблицу
идемпотентных ответов.

## Оптимизация остальных страниц

| Страница / операция | Реализованная загрузка и обработка |
| --- | --- |
| Нагрузка учителей | Серверная месячная/недельная сводка. Уроки выбранного учителя загружаются при открытии подробностей; опубликованные снимки не передаются клиенту. |
| Справочники | Метаданные без уроков. Ссылки перед удалением и влияние недоступности проверяются отдельными запросами. Сохранение обычной записи не проходит по всем урокам ради обновления подписей. |
| Учебные планы | Планы и назначения выбранной четверти. Переключение четверти загружает новую область; сохранение сохраняет планы остальных четвертей. Редактор четвертей меняет метаданные без передачи списка всех планов. |
| Печать | Индекс без полного черновика; предпросмотр выбранных групп и недели. Связанные группы добавляются только для подписей совместных занятий. |
| Замены и переназначения | Страница загружает уроки по фильтрам. Предпросмотр читает все группы на необходимых датах для проверки ресурсов и совместных уроков. Применение/отмена обновляют дни в рабочей области; бессрочные назначения включают будущие уроки выбранного потока. |
| Время, перемены, календарь | Метаданные при открытии. Серверный предпросмотр и применение только затронутых дат; сохранение настроек звонков без применения не читает расписание. |
| Копирование, объединение, очистка, мероприятия | Клиент отправляет параметры операции. Сервер проверяет занятость всех групп на затронутых датах и сохраняет изменённые дни. При копировании учитываются также часы всей четверти выбранных и связанных групп. |
| Автосоставление | Серверное задание в отдельном Worker: запуск, проценты, отмена, применение. HTTP-ответ не содержит сгенерированную сетку четверти. Применение и статус задания сохраняются атомарно; повтор запроса безопасен. |
| Ученикам и учителям | Кеш небольшого индекса публикаций; проекция только запрошенной четверти и группы/учителя. Кеш не удерживает сетки всех опубликованных четвертей. |
| Публикация | Анализ и снимок только выбранной четверти. |

### Проверка на большой школе

Подробные измерения: `admin-data-performance-2026-10-14.json`.

| Ответ API | Размер после перехода |
| --- | --- |
| Справочники, календарь, звонки | около 94 КБ каждый |
| Учебные планы выбранной четверти | около 520 КБ вместо 4,4 МБ всех планов и 60 МБ общего состояния |
| Месячная сводка нагрузки 131 учителя | около 59 КБ |
| Уроки выбранного учителя за месяц | около 16 КБ в проверенном примере |
| Занятия физики группы 10А за четверть | около 26 КБ |
| Предпросмотр печати двух групп за неделю | около 24 КБ |
| Запуск автосоставления для 74 групп | около 1 КБ запроса |

Все семь административных страниц проверены в браузере: полных запросов
`/api/state` нет, ошибок JavaScript нет. Проверены переключение четвертей,
подробности нагрузки, А4 для 10А, расчёт и применение расписания 1А на копии,
запуск расчёта всех 74 групп и отмена. Во время фонового расчёта запрос каталога
занял около 4 мс, отмена с закрытием диалога — около 116 мс. Размеры и времена
измерены локально; результат зависит от оборудования и выбранной области.

Тяжёлый полный пересчёт остаётся вычислительно дорогим. Он больше не выполняется
в браузере или основном потоке HTTP-сервера, но подготовка четверти и финальная
валидация/транзакция выполняются на сервере синхронно. Рабочая база не использовалась
для тестовых изменений.

Сборка и 298 автоматических тестов прошли; отдельная проверка фоновых заданий
включает отмену, проверку владельца, устаревшую версию, повтор запроса и откат при
сбое записи статуса. Нагрузочная проверка сохранения на копии заменила ID всех
16 601 уроков четверти, сохранив содержание занятий. Она проверяет запись больших
пакетов (33 202 старых и новых ID), а не скорость генератора. Применение заняло
около 1,14 с; незатронутые дни и опубликованные снимки сохранились.

### Ограничения и совместимость

- Старый `/api/state` и полные ответы по умолчанию оставлены для совместимости;
  обычные страницы используют ограниченные запросы и `response=compact`.
- Опубликованный снимок выбранной четверти всё ещё разбирается как JSON внутри
  сервера. Клиент получает только нужную проекцию.
- История старых замен остаётся доступной. Новые записи истории ограничены
  областью операции, но могут включать контекст остальных групп на этих датах.
- Локальная отмена после массовых серверных операций очищается, как и на первом
  этапе. Замены и переназначения сохраняют свою серверную отмену.

## Что сохраняется при переходе

Публикация остаётся отдельным снимком: изменение черновика не меняет то, что
видят ученики и учителя. Проверки конфликтов должны учитывать остальные группы
на тех же датах, даже если они не видны пользователю. Объединённые занятия и
замены нельзя сохранять частично. Архивные записи и история не удаляются.

Широкие административные операции следует переносить отдельно: их область
может быть месяцем, четвертью или несколькими группами, а не одной неделей.
