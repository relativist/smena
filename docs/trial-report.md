# Пробная эксплуатация: техническая проверка

## PostgreSQL 18: повторная проба от 16 октября 2026 года

Связный сценарий теперь проверяется в обоих хранилищах. `npm test` сохраняет пробу SQLite; `npm run test:postgres` запускает PostgreSQL-пробу в собственных временных схемах тестовой базы. Проверены настройка школы, генерация через серверные задания, изменение дня, массовая очистка и пересчёт, замена и возврат преподавателя, публикация, публичные страницы, печать, сохранность публикации после правки черновика и восстановление `.smena.gz` в другую схему с сохранением локального администратора. Временные схемы и резервные файлы автоматической пробы удаляются после теста.

При браузерной проверке найдено отличие PostgreSQL от SQLite: чтение с пустым списком дат строило `IN ()` и ломало предпросмотр массовых действий. Исправлена общая обработка пустых дат и групп: они дают пустое расписание без такого SQL. Добавлена регрессия через реальные preview/apply очистки, повторную генерацию и пустые области переназначений.

На отдельной пробной школе PostgreSQL подготовлены 40 групп, 50 преподавателей и 24 кабинета, без демонстрационных записей SQLite. Четверть — 7 октября–1 ноября 2030 года; планы — 120 уроков на группу, всего 4 800. Машина: Intel Core i5-13500, Node.js 26.8.2, PostgreSQL 18.6. Генерация выполнялась серверным worker; в браузере проверялись прогресс, отмена и применение.

## Резервная копия и восстановление

Команды `npm run db:backup` и `npm run db:restore` испытаны на базе с 4 800 сгенерированными уроками и публикацией. Копия создана при работающем сервере, с учётом SQLite WAL. Восстановление выполнено в новый файл; отдельный сервер открыл его на другом порту.

- Прежний логин и пароль работают.
- Полное состояние черновика совпадает, включая справочники, планы, календарь, звонки и настройки.
- Опубликованный снимок, ответы для учеников и учителей и печатный пакет из 40 групп совпадают.
- Проверка внешних ключей обеих баз не обнаружила ошибок.
- Резервная и восстановленная базы имеют права `600`.
- Некорректный источник, существующее назначение и оставшиеся файлы `-wal`, `-shm`, `-journal` рядом с назначением вызывают отказ без перезаписи.

## Исправление, найденное во время проверки

Один корректный запрос добавления новых кабинетов, учителей и групп со связями между ними приводил к ошибке внешнего ключа. Порядок сохранения исправлен: кабинеты → учителя → группы → подгруппы. Операция остаётся одной транзакцией. В `scripts/catalog.test.ts` проверяются совместное добавление связанных записей и отказ при неверной ссылке без изменения каталога и версии.

Начальное демонстрационное расписание содержит исторические конфликты; его нельзя считать готовой публикацией школы. Для связной пробы оно очищалось только во временной базе. Масштабная проба использует отдельную четверть и не публикует исходную демонстрационную четверть.
